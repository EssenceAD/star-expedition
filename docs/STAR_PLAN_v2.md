## 0. 킹스레이드 캡처에서 뽑은 것 (분석)

### 0-1. 화면 문법 (모든 화면 공통)
| 요소 | 킹스레이드 | 우리 적용 |
|---|---|---|
| 상단 공통 바 | 왼쪽: ← 뒤로 + 화면 이름. 가운데~오른쪽: 행동력(번개)·금화·루비 각각 [+] 버튼, 우편·채팅 아이콘. **모든 화면 동일 위치** | 동일 구조. 행동력·금화·별가루 + 우편·채팅. 모든 화면에서 같은 자리 |
| 월드 채팅 한 줄 | 상단 바 아래 오른쪽에 「닉네임 : 대사」 한 줄이 계속 흐름(어느 화면이든) | 동일. AI·실유저 채팅 한 줄 티커 + 누르면 채팅창 |
| 탭 | 상단 가로 탭(전체/전방/중앙/후방/미보유 등), 선택 탭은 진한 남색+금 테두리 | 동일 |
| 버튼 위계 | 주 버튼 = 밝은 하늘색 광택 + 흰 굵은 글씨 / 위험·특수 = 주황 / 비활성 = 회색 | 우리 색으로 위계만 따라가기(주·보조·위험·비활성 4단) |
| 패널 | 장식 금속 테두리(모서리 문양) + 진한 남색 또는 양피지 바탕 | 별자리·별빛 문양 모서리 + 밤하늘 남색 / 양피지(정보 화면) 2종 |
| 빨간 알림점 | 아이콘 오른쪽 위 N·숫자 배지 | 동일 |
| 영웅 카드 | 세로 카드: 큰 상반신 일러스트, 왼쪽 위 직업 문장, 오른쪽 위 레벨, 이름 띠, 아래 별 5개(+각성 숫자), 「룬 장착」 같은 상태 태그 | 동일 구조, 우리 테두리·문장 |
| 장비 아이콘 | 정사각 칸, 등급별 테두리 색, 왼쪽 위 티어(T6), 강화 수치 | 동일 |
| 로딩 화면 | 영웅 전신 일러스트 + 별 등급 + 칭호·이름 + 팁 한 줄 | 동일. 로딩마다 영웅 랜덤 |
| 타이틀 | 영웅 단체 키 아트 한 장 + 로고 오른쪽 위 + TAP TO PLAY + 공지·언어·로그아웃 버튼 | 동일 구도, 우리 단체 키 아트(창립 멤버 13명) |
| 승리 | 화면 가운데 거대한 금빛 문장 엠블럼 + VICTORY + 점수/순위 변화 | 별 문장 엠블럼 + 「승리」 |

### 0-2. 로비(마을) 구성
- 배경 = 그려진 마을 전경(스크롤), 영웅 몇 명이 서 있음
- 왼쪽 위: 내 초상 + 닉네임 + 레벨·경험치, 그 아래 버프(부스터 남은 시간)
- 왼쪽 접이식 패널: 진행 중 퀘스트, 이벤트(남은 시간)
- 오른쪽 큰 원형 버튼: 월드보스, 레이드, 영웅의 여관(=전투 준비/모험)
- 아래 원형 아이콘 줄: 영웅, 가방, 미션, 업적, 친구, 특별상점(FREE 말풍선), 포탈
- → **우리 로비도 이 배치**: 지금 버튼 격자 → 마을(여관) 배경 + 아래 아이콘 줄 + 오른쪽 큰 버튼 + 왼쪽 퀘스트/이벤트 패널

### 0-3. 모험(필드)
- 스테이지 목록이 격자가 아니라 **월드 지도 위 길 따라 이어진 점(노드)** — 별 3개, 현재 위치에 영웅 표시
- 오른쪽에 월드보스·레이드·전투준비 버튼 유지
- 지도 화면 안에 토벌 전투·상급 던전·도전의 탑 입구

### 0-4. 전투 준비
- 왼쪽: 영웅 카드 격자(전체/전방/중앙/후방 탭, 선택된 카드에 체크)
- 오른쪽: 현재 파티 4장 + 부스터(전리품 2배 1시간) 토글 + 행동력 소모 표시 + **[반복 전투] [전투 시작]**

### 0-5. 전투 HUD
- 왼쪽 위 AUTO · ×1.5, 그 아래 DPS & HPS & STAT 미터(초상 + 수치)

## 1. 1단계 A덩어리 수정 (지금 바로)
1. **첫 진입:** 프롤로그 → 바로 1-1 전투 → 승리 → 로비. 프롤로그는 글자만 9장 말고 배경 + 초상 + 대사(5장 이내)
2. **전투 전 대사:** 파티가 필드에 서 있는 상태에서 대사
3. **진형 → 3구역 위치 체계로 변경(킹스레이드 문법):** 직업마다 위치 고정 — 전방(기사·전사·격투가), 중앙(암살자·드루이드·기계공학자), 후방(궁수·마법사·사제). 화면 배치는 위치대로 자동. 영웅 목록·편성에 전체/전방/중앙/후방 탭
4. **시작 영웅 5명**(다섯 별 전원)
5. **피해 숫자** 대상별 가로 흩뿌림
6. **소탕 → [반복 전투]로 이름·구조 변경:** 즉시 완료 + **행동력** 소모(시간 회복, 레벨업 시 가득). 전투 준비 화면에 [반복 전투 n회] [전투 시작] 나란히
7. **부스터**(전리품 2배 1시간, 게임 재화) 자리
8. **상단 공통 바·채팅 한 줄**을 모든 화면에 고정(지금 로비만 있는 것 통일). ← 뒤로 + 화면 이름 / 행동력·금화·별가루 [+] / 우편·채팅
9. **장 클리어 전설 영웅:** 바로 합류 + 등장 연출(초상 + 대사 + 「합류!」)
10. 이름 「따뜻한밤」, 컷인 규칙, 사투리 임시 대사 — 지금대로
11. 화면 흐름도에 각 화면 "로비에서 몇 탭", "첫 실행→첫 전투 몇 탭" 표시. main에 합쳐서 배포

## 3. C덩어리 — 콘텐츠
- **필드 지도:** 스테이지를 지도 위 길 노드로(격자 대체), 별 3개·현재 위치 영웅 아이콘. 지도 안에 토벌·상급 던전·탑 입구
- **토벌 전투:** 장 보스 재도전(하루 n/5), 장비 재료
- **상급 던전:** 장별 장비 던전(n/5)
- **도전의 탑:** 층·주간 랭킹(체크인 심연 코드 재사용)
- **요일 던전:** 경험치/금화/강화석
- **레이드(협동):** 8인(내 4 + AI/길드원 4), 티어 재료
- **월드보스:** 공용 체력(체크인 하늘 균열 서버), 주간 랭킹
- **결투장 3리그:** 승리의 리그(기본) / 영광의 리그(서로 영웅 1명씩 금지 후 선택, 특정 시간대) / 최후의 리그(파티 3개, 상위 리그 해금) + 리그 점수·순위·리그 상점. 상대는 실유저 덱 또는 AI 덱
- **영웅 외전(스토리북):** 영웅 골라 외전 스토리 → 클리어 보상(전용보물·기억의 조각·코스튬). 멤버 인연 외전(오래된 지도 등)도 여기
- **이정표:** 진행 단계별 보상(20/26) + 모두 받기

## 5. 2단계 — 비주얼 정체성 (1단계 끝나면)
킹스레이드처럼 **화면 전체가 한 세트로 보이게.** 먼저 「스타일 보드」 1장 → 형철 승인 → 토큰 파일에 반영 → 전 화면 적용.
- **팔레트:** 밤하늘 남색(바탕) + 별빛 금(테두리·강조) + 양피지(정보 패널) + 하늘색(주 버튼) + 주황(특수) + 빨강(알림). 등급색 6단계
- **장식 문양:** 패널 모서리·탭·카드 테두리에 우리 문양(별자리 선·별 가시·초승달). 킹스레이드 넝쿨 문양 복제 금지
- **폰트 3종:** 한글 제목(굵고 장식적인 판타지 세리프 계열 + 외곽선·그림자) / 한글 본문(가독성) / 숫자·영문(굵은 숫자 전용, 금속 그라데이션 가능). 상업 무료 라이선스(OFL 등)만, 웹폰트 용량 고려
- **아이콘 세트:** 로비 원형 아이콘(금속 링), 스킬 아이콘(그림 아이콘 + 마나 점), 재화 아이콘, 직업 문장 9종, 등급 테두리. 이모지 전부 교체
- **화면 템플릿:** 상단 공통 바 / 탭 / 카드 격자 / 목록 / 팝업 / 확인창 / 보상창 — 6~7개 틀로 모든 화면 조립
- **타이틀:** 창립 멤버 단체 키 아트 + 우리 로고 + TAP TO PLAY
- **로비:** 여관 마을 전경 + 서 있는 영웅 + 0-2 배치
- **로딩 화면:** 영웅 일러스트 + 별 + 칭호 + 팁
- **승리/패배 엠블럼**, 레벨업·합류·뽑기 연출
- **전투 HUD:** 0-5 그대로(상반신 크게 튀어나오는 패널, 그림 스킬 아이콘, DPS&HPS&STAT)

## 6. 3단계 — 그림
등신·그림체 통일(3.5~4등신), 표정(공격 기합·피격·쓰러짐 눈 감음·승리), 자연스러운 쓰러짐 자세, 영웅 카드 일러스트(세로), 로딩용 전신 일러스트, 표정 초상화 6종, 별 단계 코스튬, 황짐승 등 비개척자 기준 그림(설정화 3~4안→선택), 몬스터·보스 추가. AI 더빙은 그 뒤.
