# 화면 흐름도 (자동 생성 · tests/flow.test.ts)

- 첫 실행 → 첫 전투: **2탭** (타이틀 「원정 출발」 → 1-1 필드에서 프롤로그 5줄, 스킵 1탭 또는 5탭 → 전투 시작)
- 첫 전투 승리 → 「원정대 여관으로」 1탭 → 로비
- 원칙: 주요 기능 1탭 · 모든 기능 3탭 이내 (STAR_PLAN_v2 최상위 원칙)

| 화면 | 로비에서 탭 수 | 이 화면에서 갈 수 있는 곳 (누르는 것) |
|---|---|---|
| 타이틀 | 1 | 전투 (원정 출발 (처음: 프롤로그 > 1-1))<br>로비(여관) (원정 출발 (이어서)) |
| 로비(여관) | 0 | 모험 (모험 (오른쪽 큰 버튼))<br>전투 준비 (왼쪽 「다음 스테이지」 > 전투 준비)<br>영웅 목록 (영웅 (아래 줄))<br>전투 준비 (편성 (아래 줄))<br>가방 (가방 (아래 줄))<br>상점 (상점 (아래 줄 · 상단 바 [+]))<br>타이틀 (설정 > 타이틀) |
| 모험 | 1 | 전투 준비 (스테이지 고르고 「전투 준비」)<br>로비(여관) (뒤로) |
| 전투 준비 | 1 | 전투 (전투 시작)<br>영웅 정보 (영웅 카드 길게 > 정보)<br>모험 (뒤로) |
| 전투 | 2 | 로비(여관) (결과 > 로비)<br>모험 (결과 > 모험)<br>전투 (결과 > 다시 / 다음)<br>전투 준비 (패배 > 편성) |
| 영웅 목록 | 1 | 영웅 정보 (영웅 카드)<br>로비(여관) (뒤로) |
| 영웅 정보 | 2 | 영웅 목록 (뒤로) |
| 가방 | 1 | 로비(여관) (뒤로) |
| 상점 | 1 | 로비(여관) (뒤로) |
