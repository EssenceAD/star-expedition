# 화면 흐름도 (자동 생성 · tests/flow.test.ts)

- 첫 실행 → 첫 전투: **2탭** (타이틀 「원정 출발」 → 1-1 필드에서 프롤로그 6줄, 스킵 1탭 또는 6탭 → 전투 시작)
