# 첫 플레이 피드백 (10/17 17:45~17:52 형철 직접 플레이)

캡처: `docs/captures/play_1017/01~26.png` (번호는 아래 항목 옆 괄호)
공통 결론: **「폰트·배경·가독성·겹침」** — 화면마다 같은 종류의 문제. 아래 0번 공통 규칙을 **모든 화면**에 적용하고, 1~ 은 자리별.

## 0. 공통 규칙 (모든 메뉴 화면 — 상점·길드·랭킹·친구·미션·콘텐츠·모험·편성·가방 포함)
1. **글씨 3종만**(FONT_FINAL): 본문 Noto Serif KR 600 / 제목·이름 Hahmlet / 숫자 Cinzel. 남은 기본 고딕·다른 서체 전부 찾아서 교체. 결과 화면·출석 팝업·말풍선·미터기 포함.
2. **배경 위 맨글씨 금지**: 그림 배경 위에 바로 놓인 설명 글씨(콘텐츠 설명 줄·도전의 탑 「최고 층」·요일 던전 설명·편성 아래 설명·모험 아래 설명 등)는 전부 **남색 유리 띠/판 안**으로. 띠 없이 그림 위에 글씨 두지 않기.
3. **메뉴 화면 배경**: 지금 콘텐츠·미션·랭킹·길드·친구 등은 로비 마을 그림이 그대로 → 메뉴 화면은 배경 그림을 **흐리게(blur 6px) + 어둡게(남색 40%)** 깔아서 패널이 떠 보이게. 위 띠(재화 바 아래 하늘 그림)와 아래 배경이 다른 그림이라 따로 놂 → 위 띠도 같은 배경 이어지게(한 장 배경이 화면 전체를 덮도록).
4. **왼쪽 세로 메뉴**(콘텐츠·미션·랭킹 등): 아이콘 없는 칸 금지 → 전부 그림 메달 아이콘(`ui/menu/` 새 12종 포함, 아래 목록). 글씨 Noto 15.
5. **패널을 억지로 가로로 늘리지 않기**: 레이드·월드 보스 카드처럼 내용이 적은 패널은 최대 폭 640px, 가운데 정렬. 버튼도 최대 폭 360px.
6. **스크롤 없이 한 화면**: 844×390에서 주요 버튼(도전·전투 준비 등)은 스크롤 없이 보여야 함. 넘치면 목록 쪽을 줄이거나 스크롤 영역 안으로.
7. **불투명 사각 배경 없애기**: 말풍선·캐릭터 이름 표·DPS 등에 들어간 사각 불투명 배경 → 없애거나 반투명 남색 알약 + 글씨 그림자.

## 1. 로딩·첫 화면 (01~03)
- 로딩에서 넘어가지 않을 때가 있음(01, 결국 넘어감) → 로딩 진행 막대가 멈추면 5초 뒤 「다시 시도」 버튼. 에셋 로딩 실패 하나가 전체를 막지 않게.
- 노엘 전신: 다리 짧고 머리 큼 → 기획 쪽이 8등신으로 다시 뽑아 `fullbody/noel.png` 교체(코드 할 일 없음).
- 전투 우측 상단 「숲 동굴 1-1」과 스킵 버튼 겹침(02) → 스테이지 이름은 WAVE 판 아래 가운데로, 스킵은 오른쪽 위 단독.
- 스토리 대사 창이 아래 영웅 HUD 위에 겹쳐 보임(02) → 대사 중엔 HUD 숨김.

## 2. 전투 HUD (03, 20, 22, 24, 25)
- **영웅 이름이 HP·마나 바와 겹침** → 이름 줄 높이 확보: 이름(Hahmlet 14) 한 줄 → 그 아래 HP → 마나. 직업·레벨은 이름 오른쪽 작게, 겹치면 직업 생략.
- **스킬 아이콘·초상화·자동 토글이 칸 아래로 잘림** → HUD 칸 높이 안에 다 들어오게(아이콘 크기 줄이거나 칸 높이 +10px). 쿨 숫자도 잘리지 않게.
- **스킬 쓸 수 있음 / 없음 차이가 작음** → 쓸 수 있음: 원래 밝기 + 금테 반짝 + 살짝 위로 뜸 / 쿨타임: 채도 0 + 어둡게 55% + 남은 초 크게 / 마나 부족: 채도 30% + 파란 자물쇠 점.
- **말풍선 없애기**(「다치믄 내한테 바로 온나」 등 전투 중 혼잣말) → 전투 중 말풍선 끔. 스킬 쓸 때 컷인에만 대사.
- **치명타 숫자 위 「치명타」 글씨 빼기** → 폭발 별 + 큰 금 숫자만.
- 결투장 적 이름 아래 사각 불투명 배경(24) → 없애기(0-7).
- 결투장 등에서 캐릭터가 화면 아래 HUD에 잘림(24) → 전투 바닥선을 HUD 위로 올리거나 캐릭터 배율 살짝 줄이기.
- **DPS 미터기(25)**: 머리판에 「DPS」가 판과 안 맞고, 줄이 판 밖으로 넘치고 잘림 → 판 높이를 줄 수에 맞추고, 한 줄 = 초상화 20 · 이름 · 숫자(오른쪽 정렬) / 그 아래 막대 + 초당(작게, 막대 오른쪽 안). 머리판 글씨는 Hahmlet 「피해량」, 판 그림 안쪽 여백 안에서만.

## 3. 레이드·월드 보스 (19, 20, 21)
- 레이드 화면 겹침 많음: 보스 이름·체력바·누적 피해·남은 시간·부위(팔·머리·코어)·그로기·대사가 서로 겹침(20) → 위쪽 정보 배치 다시:
  - 왼쪽 위: 보스 초상화 + 이름 + 체력바(넓게) + 체력 숫자(바 안 오른쪽)
  - 그 아래 한 줄: 부위 3칸(작게) + 그로기 바
  - 오른쪽 위: 남은 시간(큰 숫자) / 누적 피해(작게) — 체력바와 안 겹치게
  - 화면 위 가운데 「월드 보스 · 60초 동안 피해 주기」 문구는 시작할 때 2초만 띄우고 사라지기.
- **타격 부위 점선 상자 어색함** → 점선 상자 대신 보스 몸 위에 은은한 빨간 표적 링(약점 마크) 아이콘, 파괴되면 깨지는 효과.
- 「줄 바꾸기」 큰 금 버튼이 너무 크고 튐 → 원형 그림 버튼(작게) 오른쪽 아래.
- 결과 화면 글씨(21): 「팔 못 부숨·머리 못 부숨」 같은 줄이 맨글씨 → 결과 표(남색 판 안에 항목: 값 2열), Noto 13. 「못 부숨」 대신 부위 아이콘 + ✕/✓.
- 콘텐츠 메뉴의 월드 보스 화면: 도전 버튼이 스크롤 아래로 숨음(14) → 순위 표 높이 줄이고 도전 버튼 항상 보이게(0-6).

## 5. 콘텐츠 메뉴 (07~15)

## 11. 새 기능 — 장비 소환 연출 (가챠, 도파민)
- 상점 「장비 소환」에서 소환하면 **전용 연출 화면**으로 전환:
  1. 화면 어두워짐 → 바닥에 소환 마법진(`ui/gacha/circle`) 회전하며 빛남(0.8초)
  2. 마법진 위로 빛나는 상자/구슬(`gacha/orb`) 떨어짐, 흔들림 — **최고 등급에 따라 흔들림 횟수·빛 색이 미리 바뀜**(전설이면 금빛으로 변하며 3번 크게 흔들림 = 기대감)
  3. 터지며 카드 뒷면(`gacha/card_back`)들이 펼쳐짐(10연이면 5×2)
  4. 카드 한 장씩 뒤집힘(누르면 바로 다 뒤집기): 등급별 터짐 효과 — 일반 `burst_common` / 고급 `burst_uncommon` / 희귀 `burst_rare` / 영웅 `burst_epic`(보라 번개 + 화면 살짝 흔들림) / 전설 `burst_legend` + `beam_legend`(하늘에서 금빛 기둥, 화면 흰 번쩍, 금화 흩날림, 슬로우 0.5초, 효과음 크게)
  5. 다 뒤집으면 결과 정리(등급순) + 「다시 소환」「확인」
- 전설·영웅은 카드 테두리에 계속 빛이 돌고, 「NEW」 리본(`gacha/ribbon`).
- 건너뛰기 버튼(오른쪽 위)으로 바로 결과.

## 12. 상점 — 기능
- **영웅 상점에서 영웅 카드를 누르면 영웅 정보(미보유 미리보기) 화면으로** — 지금은 눌러도 아무 반응 없음. 미리보기에는 전신·스킬·능력치(1레벨 기준)·「구매」 버튼.
- 재화·소모품 칸: 품목마다 맞는 그림 아이콘 — 경험치 물약 `items/m_exp`, 강화석 `m_enh`, 스킬북 `m_skillbook`, 각성석 `m_awaken`, 초월석 `m_trans`, 재련석 `m_reroll`, 행동력 `m_stamina`, 소환권 `m_summon`, 금화 `m_gold`, 별가루 `m_stardust`. 아이콘 없는 품목 없게.
