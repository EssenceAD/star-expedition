# 전투 마감 손질 (10/17 밤 · v0.11.1 직접 플레이 후)

ANIM_1017이 들어가서 영웅 도트·장 보스·지역 배경은 확실히 좋아졌다. 남은 문제는 **이펙트가 화면을 하얗게 태우는 것**, **스킬 포즈가 오래 멈춰 있는 것**, **겹치고 잘리는 UI**다. 캡처: `docs/captures/polish_1017/`

순서: **① 이펙트 정리 → ② 스킬 멈춤 → ③ 전투 UI 겹침·잘림 → ④ 메뉴 자잘한 것**. 덩어리마다 테스트·main 합치기·배포.

---

## ① 이펙트가 화면을 하얗게 태움 (`battle_fx.jpg`, `skill_hold_seq.jpg`)
스킬 2~3개가 겹치면 `lighter`가 계속 쌓여서 영웅이 안 보일 만큼 하얘진다(회복 기둥 + 보호막 + 웅스 스킬). 레이드에만 상한을 뒀는데 일반 전투에도 필요하다.
- **알파 낮추기:** 이미지 이펙트 기본 알파 0.85 → **0.6**. `heal`·`pillar`·`buff`는 **0.45**. 보호막 유지(1↔2)는 지금 값에서 한 단계 더 낮춘다.
- **크기 상한:** 이펙트 높이는 **대상 키의 1.3배까지**, 범위기라도 화면 높이의 45%를 넘지 않게 한다. `heal` 기둥은 폭을 대상 몸통 정도로 줄인다(지금은 영웅 둘을 덮음).
- **같은 대상에 겹치는 개수:** 한 대상 위에 동시에 그리는 이미지 이펙트는 **최대 2개**. 새 것이 오면 가장 오래된 것부터 빨리 사라지게 한다.
- **화면 전체 상한:** 일반 전투도 동시에 그리는 이미지 이펙트 **최대 6개**(레이드 10개 유지).
- **영웅 그림에 이미 그려진 이펙트와 중복:** 새 스킬 칸(`m2r1c2`)은 그림 안에 불꽃·바위 같은 효과가 이미 있다. 그 영웅이 시전자일 때는 시전자 위치에 겹치는 큰 이펙트는 빼고, **대상 쪽 이펙트만** 그린다.
- 결과 기준: 스킬 3개가 동시에 터져도 영웅 얼굴과 몸 윤곽이 보여야 한다.

## ② 스킬 포즈가 2초 넘게 멈춰 있음 (`skill_hold_seq.jpg`)
웅스 스킬을 GIF로 0.2초 간격으로 뽑아 보니 **발동 칸(`m2r1c2`)이 약 2.4초 동안 그대로**다. 명세 타이밍(300/120/380/300ms)보다 훨씬 길다. 스킬 상태가 끝날 때까지 hit 칸을 붙잡고 있는 것 같다.
- 스킬 4칸은 명세 시간대로 한 번 재생하고, 그 뒤엔 **대기(숨쉬기) 루프로 돌아간다**. 스킬 효과(다단 히트·지속 피해)가 남아 있어도 몸은 멈추지 않는다.
- 다단 히트 스킬이면 `c1 → c2`만 짧게 반복(타격마다 1번)하고, 끝나면 `c3` → 대기.
- 평타도 같은 문제가 있는지 확인한다(0.57초 한 번 → 대기).
- 이게 "뚝딱거림"의 가장 큰 남은 원인이다. 고친 뒤 웅스·고느끼·콩선생 GIF를 다시 찍어 비교.

## ③ 전투 UI 겹침·잘림 (`battle_fx.jpg`, `battle_cutin.jpg`)
1. **DPS 판 탭 「피해·회복·받은 피해」가 위쪽 장식 테두리에 가려진다.** 탭 줄을 장식 아래로 내리거나 장식 높이를 줄인다.
2. **컷인이 DPS 판 아래에 깔린다.** 컷인은 모든 HUD 위(보스 HP바 제외)로 올린다.
3. **컷인 스킬 이름이 오른쪽 끝에서 잘린다**(「안정 취하이스…」). 글씨가 화면 안에 들어오게 오른쪽 여백을 두고, 길면 글씨 크기를 줄인다.
4. **보스 HP바가 「숲 동굴 1-10」 스테이지 이름과 겹친다.** 보스전일 때는 스테이지 이름을 HP바 아래 왼쪽(누적 피해 옆)으로 옮기거나 숨긴다.
5. **아래 영웅 카드의 이름·직업·Lv 글씨가 카드 위쪽 금테에 걸쳐 있다.** 글씨를 테두리 안쪽으로 4px 내린다.
6. **영웅 4명이 너무 붙어서 겹친다**(이카몰리·콩선생·고느끼가 서로 가림). 줄 간격을 넓히거나 후방 영웅을 살짝 위로(y −12) 엇갈리게 세운다. 새 도트가 커져서 생긴 문제다.
7. **스킬 아이콘 쿨다운이 회색 덩어리로 보인다.** 쿨다운 중에도 아이콘 그림이 알아보이게 어둡게만(밝기 45%) 하고, 숫자는 가운데에 흰 글씨 + 검은 외곽선.

## ④ 메뉴 자잘한 것 (`hero_info.jpg`, `portal_raid.jpg`)
1. **영웅 정보:** 왼쪽 영웅 목록이 전신 그림 위에 얹혀 있어서 그림이 가려진다. 목록에 반투명 남색 판을 깔거나 전신 그림을 목록 오른쪽으로 민다.
2. **콘텐츠 → 레이드:** 「레이드 도전」 버튼 아래가 텅 비었다. 보스 그림(anim1 r0c0)을 크게 넣고, 패턴 아이콘(광선·포효·내려찍기)과 지난 기록(최고 피해·클리어 횟수)을 채운다. 월드 보스도 같은 형식.
3. **승리 화면:** 캡처 시점에 별이 2개만 보였다. 애니메이션 중이었을 수 있으니 확인만.
