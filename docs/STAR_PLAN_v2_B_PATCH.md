# 별의 원정대 — B덩어리 보강 (STAR_PLAN_v2 §2 위에 덮어쓰는 기준)

> 형철 리뷰(2026-10-17): 지금 B는 체크인 설정을 그대로 가져와서 킹스레이드 시스템과 거리가 있음.
> 이 게임은 횡스크롤 킹스레이드 스타일이므로 장비·강화·영웅 수집은 킹스레이드를 따라간다.
> 숫자는 전부 src/config.ts, 색·아이콘은 tokens.ts 원칙 그대로.
> 진행 시점: 지금 하는 §3 C덩어리를 끝낸 직후, §4 D 들어가기 전에 이 문서부터.

## 1. 성장 깊이 — 킹스레이드 수준으로
- 장비 강화: 체크인식 짧은 단계(+10)가 아니라 **긴 강화 사다리**로. 킹스레이드 캡처 기준 고단계(+60대)까지 있음.
  우리 최대치·구간은 config로 잡되, 구간마다 외형이 바뀌는 지점(예: +10·+20·+30…)을 둔다. 파괴 없음 유지.
- 영웅 초월: **5단계 초월**을 다 해야 만렙. 레벨 상한 → 각성 → 초월 1~5 순서가 한눈에 보이게.
- 장비 등급(T단계·별)·옵션 재설정·룬(보석)·전용 무기 강화는 STAR_SPEC §10 그대로 살리되, 단계 수는 위 기준에 맞춰 늘린다.
- 소프트캡 유지: 위로 갈수록 효율이 떨어져 시간이 지나면 다 비슷한 선으로 모이게.

## 2. 장비·강화가 "눈에 띄게" — 지금 제일 약한 부분
지금 문제(캡처): 장비 칸이 작은 기호(칼·방패·반지)뿐, 가방은 빈 화면이 넓음, 「강화 성공 +1」이 평범한 상자 하나.
- **장비 아이콘을 진짜 그림으로**: 부위·등급별 아이템 아트(GPT로 Code가 뽑음, 마젠타 배경 시트). 같은 부위라도 등급마다 모양이 달라야 함.
- **등급 테두리 + 강화 단계 빛**: 등급별 테두리 색, 강화 구간마다 테두리 빛/반짝임이 한 단계씩 화려해짐. 칸 모서리에 **+N 큰 숫자**.
- **강화 화면 연출**: 아이템을 화면 가운데 크게 → 망치/빛 연출 → 성공 시 큰 금색 「+N」 숫자 터짐 + 능력치 전→후 비교. 구간 돌파(+10 등) 때는 더 큰 연출.
- **아이템 상세 카드**: 큰 아이콘, 이름(등급 색), 강화 단계, 주옵션·부옵션, 세트 효과. 킹스레이드 장비 상세처럼.
- **가방**: 칸을 더 크게·화면을 채우게. 등급·강화 빛이 그대로 보여서 가방만 열어도 "모았다"는 맛이 나야 함.
- **영웅 정보의 장비 6칸**: 지금보다 크게, 아이템 그림 + 테두리 + +N이 보이게. 빈 칸은 「장착 가능」 표시.

## 3. 영웅 — 지인 영웅과 오리지널 영웅을 같은 급으로
- 오리지널 영웅(멤버 아닌 영웅)도 **스토리·대사·초상화·카드 일러스트 퀄리티를 멤버 영웅과 같은 급**으로. 멤버만 특별해 보이면 안 됨. 각자 매력 포인트·관계·외전이 있어야 "갖고 싶다"가 생김.
- 지금 상점 초상화에 서로 너무 닮은 영웅이 있음(유월·신야군 등). 실루엣·머리·색으로 한눈에 구분되게.
- **영웅 상점 진열**: 멤버를 위에 몰지 말 것.
  - 탭: 전체 / 전방 / 중앙 / 후방 (가능하면 직업 필터도).
  - 기본 정렬은 역할이 골고루 섞이게. 멤버·오리지널 구분 표시 없음.
  - 카드: 큰 일러스트(지금 작은 흉상 → 카드 일러스트), 직업·위치 배지, 한 줄 소개, 가격. 미보유 영웅은 영웅 목록 「미보유」 탭에서도 같은 카드로.
- 영웅 가격은 전부 같은 정가 말고 등급/시기별로 다를 수 있음(config).

## 4. 경제 — 귀한 건 어렵게, 독주는 막고, 빡빡하지 않게
목표: "돈 주고라도 사고 싶은 것"은 사냥 재화를 어렵게 모아야 살 수 있다. 단, 체크인 때처럼 한 사람이 넘사벽으로 치고 나가면 안 된다.
- 화폐 3층
  - 금화: 흔함. 강화·기본 상점.
  - 별가루: 킹스레이드 루비 자리. 영웅·코스튬·특별 상품은 여기서만. 어렵게 모음.
  - 콘텐츠 훈장: 결투장 훈장, 길드 주화, 레이드 증표, 우정 포인트, 월드보스 결정 → 각 콘텐츠 상점 전용.
- 독주 방지 = **별가루·영웅 조각 주간 획득 상한**. 상한을 채워도 사냥은 계속 가능(금화·경험치·장비만 나옴).
- 행동력: 한 번에 30~40분 쓸 양, 6~8시간이면 다시 가득. 레벨업·일일 미션·우정으로 채움. 행동력 0이어도 탑·결투장·레이드 등은 각자 입장 횟수로 돌아감.
- 따라잡기: 휴식 보너스(안 들어온 날 쌓임), 성장 소프트캡.
- 시뮬 목표: 하루 30~40분 유저가 영웅 1명을 약 1~1.5주에 구매. 헤비 ÷ 보통 격차 최대 1.5배. 경제 시뮬 표를 이 기준으로 다시 돌려서 보고.
