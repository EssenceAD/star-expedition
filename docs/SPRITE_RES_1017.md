# 전투 도트 해상도 (10/17 · 형철 플레이 피드백 추가분)

> "PC·모바일 다 전투에서 캐릭터 해상도가 너무 떨어짐. 해상도가 떨어지면 움직임도 더 둔해 보이고 퀄리티는 말할 것도 없고."
> 캡처: `docs/captures/res_1017/pc_1.png`, `pc_2.png` · 비교: `docs/captures/res_1017/compare.png`

**PLAYTEST_1017.md 보다 먼저 한다 (덩어리 ⓪).** 다른 화면 고치기 전에 이게 먼저 보여야 함.

## 원인 (코드에서 확인함)
1. **`src/battle/render.ts` 의 `off` 캔버스가 360×360 논리 px(1배).**
   영웅을 이 1배 캔버스에 줄여 그린 뒤(267px → 약 145px), 본 캔버스가 dpr 배율(PC 전체화면 ≈ 2.7배)로 **픽셀 그대로 확대**한다.
   → 실제 해상도가 145px짜리 그림을 2.7배 늘린 것 = 뭉개지고 계단짐.
   → 위치도 1배 칸 단위로만 움직여서 2.7px씩 툭툭 끊김 = "움직임이 둔해 보임"의 원인.
2. 저장 도트 자체도 원본(약 400px)의 0.6배(약 267px)로 줄여 둔 것이라 PC 큰 화면에선 모자람.
3. 같은 구조: `bossCv`(760 논리 px, 1배), 잔상(trail)도 `off` 사용. 로비 걷기(`lobbyLife.ts`)도 그 캔버스 배율 확인 필요.

## 고칠 것
### A. 그리기 (코드)
- `off`·`bossCv` 등 **모든 보조 캔버스를 dpr 해상도로**: `off.width = 360*dpr` 등, `ox.setTransform(dpr,0,0,dpr,0,0)` 기준으로 그리고, 본 캔버스엔 `ctx.drawImage(off, x-180, y-300, 360, 360)` 처럼 **논리 크기를 지정해서** 붙인다 (1:1 물리 픽셀). `fitView` 에서 dpr 바뀌면 보조 캔버스도 다시 잡기.
- `drawFrame` 의 `imageSmoothingEnabled = k < 0.9` → **줄일 땐 항상 true + quality 'high'**. 지금 새 도트는 대부분 0.8~1.0배로 그려지니 부드럽게 줄어든다. (1.5배 이상 크게 그릴 때만 false)
- 위치는 소수점 그대로 (Math.round 금지) → dpr 해상도에서 부드럽게 미끄러짐.
- `#cv` 의 `image-rendering: pixelated` 는 백버퍼가 이미 dpr 크기면 영향 없음 — 그대로 둬도 되지만, 혹시 dpr 상한(3) 넘는 기기에서 늘어나면 `auto` 로.
- 로비 걷기, 편성 미리보기, 영웅 정보 도트 미리보기 등 **도트 그리는 모든 곳**에 같은 규칙.

### B. 새 도트 1.5배 (그림은 내가 올려 둠)
- **`public/art/px2/<36명>/`** — 같은 파일 이름(r0c0~r1c3, `_parts.json`), 원본 시트에서 다시 뽑아 **1.5배**(머리 약 72px). 체급별 키 비율은 그대로(황짐승 덩치·재희아빠 키 포함).
- 바꾸는 법: 경로 `px/` → `px2/`, **`CONFIG.combat.pxScale = 26/72`** (화면 크기는 지금과 똑같아짐). `_heads.json` 도 px2 쪽에 있음.
- 48px 머리를 가정한 다른 숫자(로비 1.4배, 쓰러짐 오프셋, 이름표·HP바 높이, 잔상 오프셋 등)가 있으면 같이 맞추기. 화면에 보이는 크기는 바뀌면 안 됨.
- `px/` 는 확인 끝나면 지워도 됨 (같은 PR에서).

### C. 불러오기 (용량 8.9MB → 20MB 라서 필수)
- 지금 `main.ts` 가 시작할 때 **36명 시트를 전부** 불러온다 → 로딩이 더 길어짐(이미 로딩 멈춤 피드백 있음).
- **필요한 영웅만**: 시작 시 = 로비에 걸어 다닐 영웅 + 현재 편성. 전투 들어가기 전 = 그 전투 아군·적(결투장 상대 포함) 시트만 `await`. 나머지는 로비 뜬 뒤 뒤에서 천천히(동시 2~3개).
- 로딩 화면 진행률은 "필수 그림" 기준으로.

### D. 움직임 (해상도 고친 김에)
- **대기 숨쉬기**: 대기 2프레임 위에 발 기준 세로 배율 1.000↔1.012 (1.6초 사인). 영웅마다 위상 다르게.
- **피격 번쩍**: 지금 흰색 덮기(0.8)가 길어서 캡처2처럼 웅스가 **유령처럼 하얗게 바랜 채** 보임 → 최대 0.5, 0.08초 안에 꺼지게, 그리고 흰색 대신 살짝 밝게(`brightness(1.6)`) 쪽이 덜 어색함.
- 공격 내딛기(lunge): 들어갈 때 빠르게(ease-out), 돌아올 때 천천히(ease-in-out). 맞는 쪽 넉백도 같은 곡선.
- 프레임 넘김 시점은 그대로, 위치·배율 움직임만 매 프레임(60fps) 보간.
