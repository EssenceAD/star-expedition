# 전투 화면 HUD 다듬기 (10/17 형철 피드백)

형철이 v0.9.4 전투 캡처에 빨간 동그라미로 짚은 곳: `docs/captures/feedback_battle_1017.png`
→ 「아직 미완성·비어 보이는·어색한 부분」. 아래 순서대로. 그림은 `public/art/ui/battle/` (목록 맨 아래).

## 1. 왼쪽 위 AUTO · ×1 버튼
- 지금: 크림색 네모 + 글씨 → 임시 버튼처럼 보임.
- 바꾸기: 둥근 금테 아이콘 버튼 2개(`auto_off/auto_on`, `speed_1/speed_2`), 지름 44px. 켜짐은 빛나는 판 + 천천히 도는 빛. 글씨는 아이콘 아래 작게(「자동」「×2」) 금 외곽선.

## 2. 오른쪽 위 「포기」
- 둥근 금테 깃발 버튼(`giveup`) 40px + 옆에 일시정지(`pause`) 같이. 누르면 확인 창(UI 키트 양피지 패널).

## 3. DPS 탭 + 목록
- 탭: `dps_tab`(칼 아이콘 남색 당김 탭)로.
- 목록: `dps_panel`(세로 남색 두루마리, 위 머리판) 안에. 지금 글씨가 패널 밖으로 넘치고 빽빽함 →
  - 한 줄 = 작은 초상화 20px · 이름 · 막대(직업색) · 숫자(오른쪽 정렬). 「초당 ○○」 줄은 지우고 막대 옆 작은 회색 글씨로.
  - 패널 폭 150px, 줄 높이 22px, 4명이면 패널 높이가 내용에 맞게. 넘치면 안 됨.
  - 기본은 접힌 상태(탭만), 누르면 펼침.

## 4. 치명타 숫자
- 「치명타」 글씨 + 숫자가 따로 놀고 숫자 폰트가 두껍고 진함.
- 바꾸기: 숫자 뒤에 `crit_burst`(주황·금 폭발 별) 깔고, 숫자는 흰색→금 그라데이션 + 진한 갈색 외곽선 2px(지금보다 얇게), 「치명타」 글씨는 숫자 위 작은 리본 느낌으로 기울여서. 0.35초 커졌다 작아지며 위로 떠오름.
- 일반 피해 숫자: 흰색 + 갈색 외곽선 1.5px, 크기 지금의 85%. 회복: 연두. (UI_POLISH 1번과 같은 방향)

## 5. 아래 영웅 HUD 칸
- 「A」(영웅별 자동) 흰 동그라미 → `hero_auto_off/on` 작은 둥근 토글(28px). 켜지면 금색으로 빛남.
- 스킬 아이콘이 어둡고 탁해 보임 → 쓸 수 있을 때는 **원래 밝기 100%** + 금테 반짝. 쿨타임일 때만 `cd_overlay`(반투명 남색 원)를 위에 덮고 남은 초를 시계방향으로 걷어냄. 마나 부족은 아이콘 채도 50%.
- 영웅 이름이 초상화 위로 겹침 → 이름은 초상화 오른쪽 칸 안에서 시작(겹치지 않게), 이름 옆 직업·레벨은 한 단계 작게.
- 스킬 아이콘 3개 크기 1.15배, 간격 균일.

## 6. 위 가운데 WAVE
- 글씨만 떠 있음 → `wave_banner`(양 끝 날개 달린 남색·금 판) 위에 「WAVE 2/2」. 웨이브 바뀔 때 판이 위에서 내려오며 0.5초 등장.
