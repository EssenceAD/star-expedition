# 캐릭터 크기 맞추기 (10/17)

## 무엇이 문제였나
전신 그림(`public/art/fullbody`, `costume_festival`)은 600×900 틀에 「옆으로 꽉 차게」 넣었었다. 그래서 방패·무기·망토가 넓은 영웅(부브·하응·클레이네·신야군·재희아빠·딸기망고모찌 등)은 키가 다른 영웅의 64~75%로 작게 보였다.

## 그림 쪽에서 고친 것 (이 커밋)
- 전신 36명 + 별빛 축제 코스튬 12벌을 **900×900 정사각 틀**로 다시 저장.
- **모든 영웅의 키(머리~발)를 860px로 통일**. 발끝은 y=890(아래 10px 여백), 가운데 정렬.
- 넓은 영웅은 옆으로 넓어질 뿐 키는 같다.

## Code가 할 것
1. 전신을 담는 상자를 **정사각형**으로 바꾼다(지금은 2:3이라 정사각 그림이 작아짐). 그림은 `center bottom / contain` 그대로 둔다.
   - `.fb` · `.recruit .rc-fb` · `#loading .ld-fb` · `.join .jfb` → 너비 = 높이. 높이는 지금 기준 그대로(영웅 정보는 화면 높이 90~100%, DENSITY_1017).
   - 정사각이 되면 옆으로 겹치는 글·버튼이 생기면 그림 상자를 뒤로(z-index) 보내거나 좌우로 조금 넘치게 둔다. 그림이 글을 가리면 안 됨.
   - `.fbc`(코스튬 카드)는 `cover`라 위치값만 다시 확인: 얼굴~상반신이 보이게.
2. 같은 원칙을 **전투 도트**에도 적용: 서 있는 키가 영웅마다 들쭉날쭉하지 않게, 체형 차이(덩치 큰 영웅 조금 크게) 정도만 남기고 표시 높이를 맞춘다. 고초상화(카드 얼굴) 역시 얼굴 크기가 카드마다 비슷한지 확인.
3. 844×390에서 영웅 정보·영입·로딩·합류 화면 전/후 캡처(부브·웅스·고느끼 비교가 잘 보이게).
