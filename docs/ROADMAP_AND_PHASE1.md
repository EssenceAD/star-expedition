# 「별의 원정대」 개발 순서 + 1단계(시스템) 명세 v1 (10/17)

세계관·영웅·인연·성장·사운드 설정은 STAR_EXPEDITION_SPEC.md, 사운드는 SOUND_PLAN.md가 기준.
이 문서는 "무엇을 어떤 순서로 만드나"를 정한다.

## 0. 개발 순서 (반드시 이 순서)
| 단계 | 내용 | 그림 |
|---|---|---|
| **1단계: 시스템** (지금) | 게임 전체 구조와 모든 시스템이 실제로 돌아가게. 화면 흐름, 데이터, 저장, 밸런스 | 지금 있는 그림 + 자리표시자만. **새 그림 금지** |
| 2단계: 비주얼 정체성 | 타이틀 로고, 폰트(한글·영문·숫자), UI/HUD 키트, 아이콘 세트를 하나의 스타일로 통일 | 스타일 보드 먼저 → 형철 승인 → 전 화면 적용 |
| 3단계: 그림 | 영웅 등신·그림체 통일, 표정, 쓰러짐/승리 등 동작 디테일, 초상화, 표정 초상화, 영웅 카드 일러스트, 나머지 영웅 | 영웅 기준 그림 승인 후 대량 생산 |

1단계 원칙
- 화면이 못생겨도 된다. 대신 **모든 색·폰트·여백·테두리·아이콘을 한 파일(테마 토큰)에서만** 가져오게 짜서, 2단계에서 그 파일만 바꾸면 전 화면이 한 번에 바뀌게.
- 그림은 지금 있는 웅스·이카몰리·왈왈콩선생·따뜻한밤·고느끼 시트와 몬스터·보스를 돌려 쓰고, 없는 영웅은 색만 바꾼 자리표시자 + 이름표.
- 모든 숫자는 config 한 곳. 밸런스 시뮬로 하루/일주일 성장 곡선 확인.

## 1. 화면 흐름
타이틀 → (첫 접속) 프롤로그 컷신 몇 장 → **로비(원정대 거점 = 여관)**
로비에서 갈 수 있는 곳:
- 모험(스토리) · 콘텐츠(탑, 협동 레이드, 길드 레이드, 월드 보스, 아레나, 요일 던전)
- 영웅(목록·상세·성장) · 편성 · 장비/가방 · 영입소(확정 영입) · 상점 · 길드 · 랭킹 · 우편 · 임무 · 설정
- 월드 채팅 창(로비 하단 한 줄, 펼치면 전체)

## 2. 전투 (파일럿 기반 확장)
- 4인 파티, **앞줄 2 / 뒷줄 2** 진형(편성 화면에서 자리 지정), 서로 안 가리게
- 패시브 1 + 액티브 3, 마나·쿨타임, 패널별 Auto + 전체 AUTO, ×1/×1.5/×2
- 보스 패턴 예고, 상태이상(기절·침묵·둔화·화상·보호막), 버프/디버프 아이콘
- 결과: 별 3개 조건(클리어 / 아무도 안 쓰러짐 / 시간 안), 보상, MVP, DPS 기록
- **소탕(자동 반복)**: 별 3개 스테이지는 N회 반복 실행 버튼. 방치 보상(오프라인 보상)도 「체크인」 방식으로
- 8인 모드: 협동 레이드·길드 레이드에서 4+4(나 + AI/길드원 파티)

## 3. 스토리
- 10장 × 장당 10 스테이지(마지막은 보스), 난이도 보통 / 어려움 / 지옥
- 장 클리어 시 별 하나 회복 연출 + 지역 전설 영웅 영입 해금
- 대화는 텍스트 + 초상화(지금은 기존 초상화), 스킵 가능
- 1단계에선 1~3장만 실제 데이터, 4~10장은 몬스터 수치만 있는 자리표시자

## 4. 영웅
- 32명 데이터 전부(STAR_EXPEDITION_SPEC §3). 그림 없는 영웅은 자리표시자
- 영입: **뽑기 없음.** 영입소에서 재화(별가루 또는 영웅별 영입 증표)로 확정 영입. 스토리·이벤트·인연으로도 해금
- 성장: 레벨 → 각성(상한 확장) · 스킬 레벨 · 초월(단계마다 특성 2택) · 전용 무기(장착 시 외형 변화 자리만) · 전용 보물(외전 스토리로 해금, 1단계는 수치만)
- 인연 조합 효과·대사(§4) 실제 적용
- 상세 화면: 능력치, 스킬 설명, 장비 슬롯, 인연, 전투력

## 5. 장비 (STAR_EXPEDITION_SPEC §10 전부 구현)
- 슬롯: 무기 · 갑옷 · 장신구 2 (직업별 무기 종류)
- 등급 일반~전설, 1~5성, 티어, 강화 +0~+10(파괴 없음), 부가 옵션 3~4줄
- **별 올리기**: 같은 장비 먹이기, 단계별 급락 확률 + 실패 누적 보정
- **옵션 바꾸기**: 한 줄씩, 기존 vs 새 옵션 선택, 티켓 소모
- **룬**: 슬롯 장착, 등급, 합성
- **소프트캡**: 치명·공속 등 상한, 상세 화면에 "상한까지 n" 표시
- 전수(강화 옮기기), 일괄 판매/분해, 가방 정렬·잠금
- 뽑기는 장비·코스튬만, 게임 재화로만(현금 결제 없음)

## 6. 콘텐츠
| 콘텐츠 | 내용 | 보상/역할 |
|---|---|---|
| 탑 | 층마다 강해짐, 10층마다 보스, 주간 최고 층 랭킹 | 별가루·룬 |
| 요일 던전 | 경험치 / 금화 / 강화 재료 (요일별) | 성장 재료 |
| 협동 레이드 (드래곤류) | 8인(내 파티 + AI/길드원), 하루 n회 | **티어 재료·장비** 주 공급처 |
| 길드 레이드 | 주간 보스, 길드원 누적 피해, 기여도 순위 | 길드 코인 |
| 월드 보스 | 전 서버 공용 체력(「체크인」 하늘 균열 서버 재사용), 일일 도전, 주간 랭킹 | 랭커 칭호 |
| 아레나 | 비동기: 다른 유저/AI 덱과 자동 전투, 점수·리그 | 아레나 코인·칭호 |
| 일일·주간 임무, 출석 | — | 재화 |

## 7. 길드·소셜·AI 플레이어
- 길드: 실제 멤버 길드 1개 + **AI 길드 여러 개**. 가입/출석/기여/길드 상점/길드 채팅
- AI 플레이어: 월드 채팅(공략 질문, 자랑, 뽑기 탄식, 길드 모집), 랭킹 채우기, 아레나 덱, 협동 레이드 동료. 「체크인」 AI 대사 데이터·채팅 서버 재사용
- 친구(「체크인」 각별한 이웃 구조 재사용 가능)
- 랭킹: 탑, 월드 보스, 아레나, 길드 레이드 기여. **DPS 미터·MVP·랭커 칭호**(채팅 이름 옆)

## 8. 재화·경제
- 금화, **별가루**(프리미엄 역할이지만 전부 플레이로 획득), 영입 증표, 강화석, 티어 재료, 옵션 티켓, 룬, 길드/아레나 코인
- 상점: 일반 / 길드 / 아레나 / 탑
- 경제 시뮬: 라이트·보통·헤비 3유형으로 1일·7일·30일 성장 곡선 → reports에 표로

## 9. 계정·저장
- 「체크인」과 **같은 Supabase·같은 계정**(게스트 포함). 저장은 별도 테이블
- 「체크인」 연동 보너스: 체크인 개척자 5명은 체크인 계정이면 처음부터 영입 등(1단계는 자리만)
- 클라우드 저장, 플래그, 패치노트, 제보 편지 「체크인」 그대로

## 10. 1단계 결과물
- 플레이 주소: 타이틀부터 로비 → 스토리 1~3장 → 영웅 성장·장비·별 올리기 → 탑·레이드·아레나·길드까지 전부 눌러서 돌아가는 상태
- 테마 토큰 파일 1개(색·폰트·여백·테두리·아이콘 경로)로 전 화면이 그려지는지 확인
- 경제 시뮬 표, 자동 테스트, 화면 흐름도(어떤 화면에서 어디로 가는지)
- 그림·폰트·UI 꾸미기는 하지 말 것 (2단계)

## 11. 2단계 미리 메모 (지금 하지 말 것)
- 스타일 보드 1장: 로고 시안 2~3, 한글·영문·숫자 폰트 후보(무료 상업 이용 가능 라이선스만), 패널·버튼·바·아이콘 샘플, 색 팔레트 → 형철 승인 후 적용
- 지금 피드백: 남색 바탕 + 금 테두리 + 이모지 아이콘 + 기본 폰트가 서로 따로 놀아서 통일감 없음
## 12. 3단계 미리 메모
- 등신 3.5~4로 통일, 그림체 통일, 표정(공격·피격·쓰러짐 눈 감음·승리), 쓰러짐 자세 자연스럽게, 표정 초상화 6종, 영웅 카드 일러스트, 황짐승 등 비개척자 기준 그림(설정화 3~4안 → 선택)
