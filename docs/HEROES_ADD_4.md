## 1. 세르미뉴 — 「별을 읽는 자」
- 직업/위치: 마법사 · 후방
- 성격: 신중하고 진중함. 말수 적지만 한마디가 정확. 게임(전투)을 정말 잘하고 아는 게 많음. 칭찬엔 살짝 웃고 넘김.
- 말투: 짧고 단정. "계산은 끝났어. 3초 뒤에 쓰러진다." / "…괜찮아, 예상한 범위야."
- 외형: 시크한 미소년. 은회색 앞머리가 눈을 살짝 가림, 남색 롱코트에 별자리 무늬 안감, 손에 떠 있는 작은 천구의(별 구슬). 표정은 무심한 반쯤 미소.
- 전투 콘셉트: 「계산형 마법사」 — 폭발형 깡토끼와 반대. 적에게 별 표식을 쌓고 한 번에 터뜨림, 적 스킬 시전 지연(디버프), 아군 쿨타임 단축.
  - 스킬1 별표식: 적 하나에 표식 3중첩
  - 스킬2 궤도 계산: 적 전체 시전 속도 감소
  - 스킬3 예지: 아군 1명 다음 스킬 쿨 감소
  - 필살 「별의 정답」: 표식 수만큼 별이 떨어짐(표식 많을수록 강함)
- 매력 포인트: 레이드에서 그로기 게이지를 잘 깎음 → "공략 담당".

## 2. 이치애 — 「꺾이지 않는 꽃」
- 직업/위치: 격투가 · 전방
- 성격: 의리 있고 인내심이 강함. 동료가 맞으면 대신 맞으러 감. 겉모습은 의외로 청순.
- 말투: 차분·다정, 싸울 땐 단호. "괜찮아요, 제가 버틸게요." / "여기까지 같이 왔잖아요. 끝까지 가요."
- 외형: 청순미 — 긴 흑발을 낮게 하나로 묶음, 흰색·연분홍 무도복(소매 넓음), 붕대 감은 주먹, 머리끈에 작은 꽃 장식. 부드러운 눈매 + 단단한 자세의 대비.
- 전투 콘셉트: 「버티는 격투가」 — 팬더(호쾌한 연타형)와 구분. 맞을수록 쌓이는 인내 게이지 → 반격.
  - 스킬1 받아치기: 짧은 시간 받는 피해 감소 + 반격
  - 스킬2 의리: 체력 낮은 아군 대신 일정 시간 공격을 받아줌(도발)
  - 스킬3 꽃잎 연권: 3연타
  - 필살 「만개」: 쌓인 인내 게이지만큼 한 방(오래 버틸수록 강함)
- 매력 포인트: 탱커 보조 겸 딜 → 전방 자리 고민을 만들어 줌.

## 3. 딸기망고모찌 — 「세 친구의 주인」
- 직업/위치: 드루이드 · 중앙 (소환형) — 황짐승(야성 변신형)과 다른 갈래
- 이름 유래: 실제 반려견 3마리 이름(딸기·망고·모찌). 게임 안에서도 세 마리 정령견을 데리고 다님.
- 성격: 유머러스하고 쾌활. 분위기 메이커, 개들 자랑이 끝이 없음.
- 말투: 밝고 장난스러움. "딸기 물어! 망고 막아! 모찌는… 일단 귀여워!" / "우리 애들 오늘 컨디션 최고야ㅋㅋ"
- 외형: 밝은 표정의 청년, 짧은 갈색 머리에 개 발자국 배지, 초록 망토와 큰 가방(간식 주머니). 옆에 색이 다른 정령견 셋 — 딸기(분홍빛, 공격), 망고(노란빛, 방어), 모찌(흰빛, 치유).
- 전투 콘셉트: 「소환형 드루이드」 — 개 3마리가 각자 역할.
  - 스킬1 딸기 출동: 공격견 돌진
  - 스킬2 망고 지켜: 방어견이 아군 앞에 보호막
  - 스킬3 모찌 핥기: 치유견이 아군 회복
  - 필살 「다 같이 산책!」: 세 마리 합체 돌진 컷인
- 매력 포인트: 개 세 마리가 화면에 같이 뛰어다님 → 귀여움 담당.
- 정령견 외형(실제 견종 모름 → 대중적으로 제일 귀여운 쪽으로): 딸기 = 레드 토이푸들(곱슬 갈색털 + 분홍 리본, 공격), 망고 = 웰시코기(노란 털·짧은 다리·큰 엉덩이, 방어), 모찌 = 비숑 프리제(하얀 솜뭉치, 치유). 세 마리 실루엣이 확실히 달라야 함.

## 4. 재희아빠 — 「세상에서 제일 바쁜 아빠」
- 직업/위치: 전사 · 전방
- 성격: 귀엽고 다소 산만함. 말투가 귀엽고 살짝 오글거리지만 속은 진국. 딸(아들) 재희 얘기를 자주 함. 동료를 가족처럼 챙김.
- 말투: 귀여운 어미. "앗 잠깐만용~ 이거 먼저 하구!" / "우리 팀 다치면 아빠 화난다아~?" / (진지할 때) "…괜찮아. 내가 지킬게."
- 외형: 둥글둥글 순한 인상, 부스스한 머리, 큼직한 갑옷인데 가슴에 아이가 그려준 듯한 삐뚤빼뚤 별 그림 패치, 허리에 작은 인형 고리. 무기는 큰 양손 망치.
- 전투 콘셉트: 「지키는 전사」 — 평소엔 산만(랜덤 효과), 아군 위기 땐 각성.
  - 스킬1 정신없는 휘두르기: 무작위 적 2~3명 타격
  - 스킬2 아빠 왔다!: 체력 낮은 아군 쪽으로 이동해 막아줌
  - 스킬3 간식 타임: 아군 소량 회복 + 사기
  - 필살 「재희야 아빠 간다」: 아군 중 하나가 위험할수록 강해지는 일격 (평소 귀여움 → 필살 땐 진지한 컷인, 반전 매력)
- 매력 포인트: 웃기다가 필살기에서 멋있어지는 반전.

## 공통
- 각 영웅: 초상화 + 카드 일러스트 + 표정 3종(기본·웃음·진지) + 횡스크롤 도트, 외전 1편(짧은 스토리) 자리.
- 관계 (형철 제공, 2026-10-17):
  - 재희아빠 ↔ 따뜻한밤: 현실 친구. 서로 막 대하면서 챙기는 사이. 대사·협공 컷인 1조.
  - 딸기망고모찌 ↔ 깡토끼: 친함. 시원시원한 깡토끼와 쾌활한 모찌 조합, 깡토끼가 개들 이뻐함. 협공 컷인 1조.
  - 세르미뉴: 특별히 친한 한 명은 없지만 **모두의 리스펙**을 받음 — 모르는 게 있으면 다들 「세르님」한테 물어봄. 다른 영웅들이 세르미뉴를 「세르님」이라 부르고 존댓말·질문하는 대사를 여러 영웅에 흩어 넣기.
    - 세르미뉴 ↔ 신야군: 스승과 제자. 신야군이 세르미뉴를 따름. 말 없는 신야군이 세르미뉴 앞에서만 질문이 많아지는 식. 협공 컷인 1조(사제 합동기).
  - 이치애: 현실 지인은 없음, 게임에서 알게 된 길드원 — 세계관에서도 「원정대(길드)에서 만난 동료」로. 특정 짝 없이 누구와 붙여도 어색하지 않은 의리 캐릭터. (Claude 제안: 길드의 별 클레이네와 길드 선후배 느낌 대사 1~2줄 정도면 자연스러움)
- 영웅 목록·상점 진열은 B 보강 문서 원칙대로 역할별로 섞어서.
