# 화면 밀도 보강 — 「꽉 찬 느낌」 (형철 2026-10-17)

> 형철: 아이콘·캐릭터가 화면을 꽉 채우는 느낌이었으면. 지금은 여백이 많아 보이고, 캐릭터 뒤 배경이 단색에 너무 환하기만 함. 전반적으로 꽉꽉 들어차 있다는 느낌.
> 원칙: 밝은 톤(시안 D)은 유지하되, 「비어 보이는 밝음」 → 「채워진 밝음」. 킹스레이드처럼 화면 가장자리까지 정보·그림이 차 있게.

## 1. 크기 키우기
- 영웅 카드(목록·상점·편성): 일러스트가 카드의 85% 이상을 차지하게. 지금 흉상이 카드 안에서 작음 → 확대해서 얼굴·상반신이 카드 위쪽을 꽉 채우고, 이름·직업 배지는 그림 위에 겹쳐 얹기(아래 따로 띠 두지 말 것).
- 영웅 정보·영입 화면의 전신: 화면 높이의 90~100%. 발끝이 하단 UI에 살짝 가려져도 됨(킹스레이드처럼).
- 아이콘(로비 하단 줄·상점 카테고리·재화·장비 칸): 지금보다 1.2~1.4배. 칸 안 여백 줄이기.
- 로비 오른쪽 큰 버튼(모험·레이드·월드보스): 더 크고 그림 들어간 버튼으로.

## 2. 단색 배경 없애기
- 캐릭터·카드 뒤 단색 크림 배경 금지. 화면마다 그림 배경을 깔고(로비=lobby.jpg, 영웅/상점=해당 화면 배경 또는 lobby를 흐리게, 영입=recruit.jpg, 길드=guild.jpg, 모험=map.jpg) 그 위에 반투명 양피지 패널.
- 패널 자체에도 질감: 양피지 결·금 테두리·모서리 장식(9-slice). 평평한 단색 박스 금지.
- 카드 배경: 등급색 그라데이션 + 은은한 별자리 문양/빛 번짐. 빈 크림색 금지.
- 너무 환한 화면은 가장자리 비네트(살짝 어둡게)·그림자로 깊이를 줌.

## 3. 빈 공간 채우기
- 목록 화면: 한 화면에 카드가 더 많이(열 수 늘리기) 또는 카드를 키워 꽉 차게. 아래·오른쪽에 큰 빈 땅 남기지 말 것.
- 로비: 마을 배경 위에 걸어 다니는 도트 영웅 몇 명, 말풍선, 반짝이 효과(살아 있는 느낌).
- 결과·보상 창: 보상 아이콘 크게, 빛 효과.

## 4. 확인
- 844×390 캡처로 전·후 비교: 로비 · 영웅 목록 · 영웅 정보 · 상점(영웅/코스튬) · 영입 · 가방 · 모험 지도. 화면 빈 면적이 눈에 띄게 줄었는지.
