## 1. 모바일: 「화면을 돌려 주세요」 없이 바로 가로로
지금은 세로로 들면 `#rotate`(「가로로 돌려 주세요」)가 화면을 덮는다. 웹에서 화면 방향을 강제로 바꾸는 건 브라우저마다 달라서 아래 3단을 다 한다.

1. **세로일 때 게임을 90° 돌려서 그린다 (모든 기기, 기본).**
   - `#rotate` 안내를 없앤다.
   - `orientation: portrait` 이면 `#stage` 를 `rotate(90deg)` 로 돌려서, 폰을 옆으로 눕히기만 하면 바로 가로 화면이 되게 한다. `fitView` 에 들어가는 너비·높이도 서로 바꾼다(창 높이 → 게임 너비).
   - **터치 좌표 변환 필수.** 캔버스·DOM 둘 다 확인. DOM 버튼은 CSS 회전이면 브라우저가 알아서 맞추지만, 캔버스에서 좌표를 직접 계산하는 곳(드래그·레이드 약점 등)은 회전을 반영해야 한다.
   - 폰을 실제로 가로로 돌리면 회전을 풀고 그대로 가로로 그린다. 화면 방향이 바뀔 때 깜빡임 없이 다시 맞추기(`resize` + `orientationchange` + `visualViewport.resize`).
2. **안드로이드(크롬·삼성 인터넷): 첫 터치에 전체 화면 + 가로 잠금.**
   - 타이틀의 「터치해서 시작」 터치에서 `document.documentElement.requestFullscreen()` → 성공하면 `screen.orientation.lock('landscape')`. 주소창도 사라져서 **「화면이 가려지는 문제」도 같이 해결**된다.
   - 실패하면(아이폰 등) 조용히 1번 방식 그대로.
   - 설정에 「전체 화면」 켜기/끄기.
3. **홈 화면에 추가 (PWA).**
   - `manifest.webmanifest`: `"display": "fullscreen"`, `"orientation": "landscape"`, 이름 「별의 원정대」, 아이콘 192·512(타이틀 로고에서 자르기).
   - iOS용: `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style: black-translucent`, `apple-touch-icon`.
   - 홈 화면 아이콘으로 실행하면 주소창 없이 가로 전체 화면이 된다. 처음 들어왔을 때 한 번만 「홈 화면에 추가하면 전체 화면으로 즐길 수 있어요」 작은 띠를 띄운다(닫으면 다시 안 뜸).
4. **가려짐 방지 공통:**
   - 높이는 `100vh` 대신 `100dvh` / `visualViewport.height` 기준으로 맞춘다.
   - 노치·홈바 쪽은 `env(safe-area-inset-*)` 만큼 HUD를 안으로 들인다(배경은 끝까지).

## 2. 채팅 입력할 때 키보드가 화면을 덮는 문제
**완전히 피할 수는 없다.** 가로 모드에서 폰 키보드가 화면 높이의 절반 이상을 차지하기 때문이다(캡처처럼). 그래도 훨씬 덜 답답하게 만들 수는 있다.
- **입력 중 전용 배치:** 입력칸에 포커스가 가면 `visualViewport.height` 로 실제 남은 높이를 잰다. 그 높이 안에 **최근 채팅 3~4줄 + 입력줄**만 꽉 차게 보여 주고, 아래 메뉴 줄과 왼쪽 판은 숨긴다. 입력줄은 키보드 바로 위에 붙인다. 지금처럼 판이 화면 가운데에 걸려 위아래가 잘리면 안 된다.
- 보내거나 키보드를 닫으면(`blur`) 원래 배치로 돌아온다.
- **키보드 없이 쓰는 빠른 채팅:** 입력칸 왼쪽에 😊 버튼을 둔다.
  - 누르면 자주 쓰는 말(「ㅎㅇ」「ㄱㄱ」「고마워요!」「같이 레이드?」「ㅋㅋㅋ」 등 8개)과 감정 표현(웃음·놀람·화남·하트 4개)이 나온다. 한 번 누르면 바로 보내진다.
  - 결투장 전투 중 😊 버튼(§3-B)과 같은 묶음을 쓴다.
- 채팅 판 크기와 줄 간격도 모바일에선 한 단계 줄인다.

## 3. 참고 영상에서 가져올 것
### A. 전투 (일반·레이드 공통)
1. **유닛 머리 위 작은 HP바:** 아군은 초록, 적은 빨강. 폭은 몸통 정도이고 피해를 입었을 때만 2초간 보인다(평소에도 켤지는 설정에서).
   - 버프·디버프는 바 위에 작은 아이콘 1줄(최대 4개)로 보인다. 지금 쓰는 상태 표시가 있으면 그 자리로 옮긴다.
2. **피해 숫자 위계:**
   - 일반 숫자는 작게, 치명타는 1.6배 주황색으로 튀어 오르며 커졌다 줄어든다.
   - 회복은 초록 `+숫자`, 보호막은 하늘색이다.
   - 숫자가 겹치면 위로 쌓이며 살짝 흩어진다.
   - 「치명타」 글씨는 지난번 결정대로 넣지 않고, 크기와 색으로만 구분한다.
3. **위쪽 HUD에 남은 시간:** WAVE 띠 옆에 `1:29` 처럼 전투 제한 시간을 둔다. 30초 남으면 빨갛게 바뀐다.
4. **DPS 판 접기:**
   - 판 오른쪽 끝에 `>` 손잡이를 둔다. 누르면 판이 왼쪽으로 쏙 들어가고 손잡이만 남는다. 상태는 기억한다.
   - 판 위에 「피해 · 회복 · 받은 피해」 3탭을 둔다. 지금 dealt·healed·taken 값이 이미 있다.
5. **승리 별 3개:**
   - 지금 승리 그림 위에 **별 3개**를 하나씩 「쾅」 박히듯 떨어뜨리고, 뒤에서 금빛 햇살이 돈다.
   - 별 조건은 ① 클리어 ② 아무도 안 쓰러짐 ③ 제한 시간 절반 안에 클리어다. 결과 화면 `.rstars` 와 같은 조건을 쓴다.
   - 별 3개를 처음 받은 스테이지는 「★3」 표시가 모험 지도 노드에 남는다(이미 있으면 확인만).
6. **큰 스킬 연출:**
   - 궁극기(3번째 스킬)가 범위 공격이면 범위만큼 반투명 원형(돔)을 0.6초 깐다. 색은 영웅 속성색이다.
   - 이미 컷인이 있으면 컷인 뒤에 이어 붙인다.
7. **마지막 일격 하얀 번쩍:** 웨이브나 보스의 마지막 적이 쓰러지는 순간 0.15초 흰 번쩍이 나고, 0.4초 느려진다(지금 전설 소환 연출과 같은 방식).

### B. 결투장
1. **VS 입장 화면(1.5초):**
   - 왼쪽에 우리 편성 카드 4장(초상화·별·레벨), 오른쪽에 상대 카드 4장이 미끄러져 들어온다.
   - 가운데 큰 「VS」가 금빛으로 박힌다. 상대 이름판에는 리그 순위·승률이 들어간다.
   - 화면을 누르면 건너뛴다.
2. **3·2·1 카운트다운:** 전투 시작 전 가운데 큰 금색 숫자를 띄운다. 숫자는 Cinzel 폰트로, 커졌다 줄어든다.
3. **팀 전체 HP 줄:** 맨 위 왼쪽은 초록(우리 편 합계 %), 오른쪽은 빨강(상대 합계 %)이다. 양쪽 대장 초상화가 들어가고, 가운데 금빛 판에 남은 시간 `01:30` 이 들어간다. 이름판 아래에는 양쪽 점수(결투장 포인트)를 둔다.
4. **😊 감정 표현 버튼:** 오른쪽 가장자리에 둔다. 누르면 4개 중 하나가 내 대장 머리 위에 2초간 뜬다. §2와 같은 묶음이다. 상대 AI도 가끔 쓴다.

### C. 상점·영웅 정보
1. **상점 영웅 목록:**
   - 위쪽 직업 필터 알약(전체·전사·기사·암살자·궁수·마법사·사제 등 우리 직업 이름 그대로)과 정렬 「전체 보기 ▾」를 둔다.
   - 카드 오른쪽 위 모서리에 **직업 아이콘 원**을 둔다(색은 직업별).
2. **영웅 정보 화면:**
   - 왼쪽에 보유 영웅 세로 목록(초상화·별·레벨)을 두고 위아래로 넘긴다. 목록을 누르면 그 영웅으로 바로 바뀌어서 정보 화면을 닫았다 열 필요가 없다.
   - 가운데 전신 그림은 크게 둔다.
3. **로비·편성 「팀 레벨」 띠:** 팀 레벨 숫자, 경험치 % 막대, 그 아래 지금 켜진 버프 아이콘 줄(출석 보너스·이벤트 등)을 둔다. 이미 계정 레벨이 있으면 그걸 쓴다.
