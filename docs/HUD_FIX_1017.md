## A. 아래 영웅 카드 (`card_woongs_zoom.jpg`)
1. **초상화 얼굴이 잘린다.** 웅스는 얼굴이 카드 왼쪽 끝에 붙어서 머리 절반이 테두리 밖으로 나간다. 다른 영웅도 얼굴 위치가 제각각이다.
   - 영웅마다 **얼굴 중심(faceX, faceY, 0~1 비율)** 값을 하나씩 둔다(`heroes.ts`나 별도 json). 카드에서는 그 점이 초상화 칸 **가로 50% · 세로 42%**에 오도록 잘라 그린다.
   - 36명 전부 값을 넣고, 36명 카드를 한 장에 모은 확인 시트를 만든다. 눈 두 개가 다 보이고 정수리가 칸 위로 잘리지 않아야 한다.
2. **초상화가 카드 위 금테 밖으로 삐져나온다**(머리카락이 테두리 위로 올라감). 초상화는 카드 안쪽 영역으로 잘라 넣는다(`clip`/`overflow:hidden`). 테두리 위로 나오는 건 없다.
3. **이름·직업·Lv 글씨가 위쪽 금테 선 위에 걸쳐 있다**(POLISH ③-5를 "고쳤다"고 했지만 그대로다).
   - 글씨 위쪽 끝이 **금테 안쪽 선보다 최소 6px(논리 px) 아래**에 오게 한다. 4px로는 부족했다.
   - 이름 줄 뒤에 남색 반투명 띠(알파 0.75)를 깔아서 테두리·배경과 섞이지 않게 한다.
   - 「전사 Lv.1」 작은 글씨는 너무 가늘고 흐리다 → 굵기 한 단계 올리고 밝기 올림(지금 금색 → 연한 금색 `#f3dca0`).
4. **스킬 아이콘 오른쪽 아래 작은 숫자**(「3」「80」 등)가 아이콘 테두리와 겹친다. 무슨 값인지(레벨? 마나?) 보이게 하려면 아이콘 밖 아래쪽 작은 알약으로 빼고, 필요 없는 값이면 지운다.
5. 쿨다운 큰 숫자는 지금 괜찮다. 다만 아이콘보다 숫자가 너무 크면 그림을 가리니 아이콘 지름의 45% 이하로.

## B. 피해량 미터 (`meter_zoom.jpg`) — 내 지난 명세에서 빠졌던 것
1. **글씨체가 두 개가 섞여 있다.** 이름은 고딕(본문체), 숫자는 세리프(장식체)라 따로 논다.
   - 미터 안의 글씨는 **전부 한 가지 본문체**로 통일한다. 숫자는 `font-variant-numeric: tabular-nums`로 자리 맞춤.
   - 장식체(Cinzel 계열)는 WAVE·남은 시간 같은 제목용으로만 쓴다.
2. **「1,295/초」가 색 막대 위에 겹쳐 있어서 안 읽힌다.**
   - 한 줄 구성: `[초상화] 이름 ……… 총 피해` 그 아래 줄에 `[막대 ███████░░░] 1,295/초`처럼 **막대 오른쪽 밖에** 초당 값을 둔다. 막대 길이를 그만큼 줄인다.
   - 글씨와 막대는 1px도 겹치지 않는다.
3. **위쪽 양피지 이름판이 비어 있다.** 「피해량」(지금 탭에 따라 「회복량」「받은 피해」) 제목을 거기 넣고, 탭 3개는 그 아래 한 줄에 그대로 둔다.
4. **판이 짧아서 마지막 줄(왈왈콩선생)이 아래 장식에 걸린다.** 판 높이를 4명 + 여백 8px에 맞추거나, 줄 간격을 줄인다. 레이드 8명일 때는 스크롤 없이 두 줄씩 접는 대신 위 4명만 보이고 나머지는 「+4」로.
5. **접기 손잡이(◀ 네모)가 판에서 떨어져 혼자 떠 있고 캐릭터와 겹친다.** 손잡이를 판 오른쪽 테두리에 붙여서 판의 일부처럼 보이게 하고(같은 금테·남색), 높이는 판 높이의 30% 정도.

## C. 왼쪽 위 버튼 (`topleft_zoom.jpg`)
- 「자동」「×1」 글씨가 배경 위에 맨글씨로 얹혀 있다 → 버튼 아래 작은 남색 알약 안에 넣는다(공통 규칙: 그림 위 맨글씨 금지).

## D. 같은 기준으로 한 번 더 훑기
- 전투 화면의 **모든 글씨**를 확대해서 본다: 테두리·막대·배경과 겹치거나 걸치는 글씨가 있으면 같이 고친다(보스 HP바 숫자, 웨이브 띠, 남은 시간, 피해 숫자 포함).
- 찾은 것 목록과 확대 전·후를 보고에 붙인다.
