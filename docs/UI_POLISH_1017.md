# UI 다듬기 (10/17 형철 피드백)

형철: 「UI·HUD도 아트적인 느낌이 나야 함」「숫자 폰트 너무 굵고 진함」「크림 바탕은 좋은데 전반적으로 조화롭지 않음」「장비가 너무 작음」「빅토리 그림 더 크게」「세레스 이름이 얼굴 가림」.

그림(UI 키트·스킬 아이콘·황짐승 수정)은 기획 쪽이 뽑아서 `public/art/ui/kit/`, `public/art/skills/`에 올림 → 올라오면 `docs/ART_UI_1017.md`에 파일 목록·9-slice 값 적어 둠. 그림이 오기 전에 아래 1~4부터 해도 됨.

## 1. 숫자 폰트 (가장 먼저)
- **메뉴·재화·능력치 숫자**: Luckiest Guy 빼기 → **Cinzel 600** (Google Fonts, OFL) — 가늘고 우아한 금장 서체 느낌. 한글 섞이면 Hahmlet 700.
  - 색: 거의 검정 대신 **진한 갈색 `#5b3a1e`**, 강조 숫자(전투력 등)만 금 그라데이션.
  - 크기는 지금과 같게, 굵기만 낮춤.
- **전투 피해·회복 숫자**: Luckiest Guy 유지(타격감) — 단 외곽선 1px 얇게, 그림자 약하게. 치명타만 크게+금색.
- tokens.ts `font.num`을 둘로 나눔: `numUi`(Cinzel) / `numHit`(Luckiest Guy).

## 2. 색 조화 — 3색 규칙
- 바탕: 크림 `#f6ecd6` (유지) / 패널 안: 더 밝은 크림 `#fbf5e8`
- 테두리·강조: 금 `#c99a3b` → 밝은 금 `#e8c46a` 그라데이션
- 대비색: 남색 `#23345e` (탭 선택·버튼·HUD 판)
- 그 밖의 색(초록·하늘·분홍 버튼 등)은 **등급색·속성색·HP/마나 바에만**. 일반 버튼은 파랑 하나 + 강조(구매·영입)는 금색 하나로 통일.
- 회색 선(1px 회색 테두리) 전부 금 테두리 또는 그림자로 교체.

## 3. 크기
- **장비 칸**: 영웅 정보 오른쪽 장비 6칸 1.4배(지금 ~64px → 88~90px), 아이콘이 칸의 85%를 채우게. 가방 칸도 같은 크기. 등급 테두리는 UI 키트 그림으로.
- **승리/패배 엠블럼**: 화면 높이의 **55~60%**(지금 ~25%). 가운데 위쪽에 크게 떠서 0.4초 튕기며 등장, 보상 카드는 그 아래로 내림. 레벨 업 엠블럼도 같은 규칙.
- 전투 아래 HUD 영웅 칸: 초상화 1.2배, 스킬 버튼 1.15배.

## 4. 영웅 카드 글씨 (세레스 이름이 얼굴 가림)
- 카드 아래 정보 띠를 **고정 높이**로: 배지 줄 / 이름 1줄 / 설명 **1줄 말줄임(…)** / 가격 버튼. 설명이 길어도 이름이 위로 밀려 올라가지 않게.
- 일러스트는 `object-position: center 15%` 정도로 얼굴이 정보 띠 위에 오게. 모든 카드에서 확인(특히 세레스·아리아·노엘처럼 머리 장식 큰 영웅).

## 5. UI 키트 그림 연결 (그림 올라오면)
- 패널(양피지·남색) → `border-image` 9-slice
- 버튼(파랑·금), 탭(기본·선택), 원형 스킬 버튼 틀, 등급별 칸 틀, 재화 캡슐, HUD 영웅 판, HP/마나 바, 제목 리본, 닫기·뒤로 버튼
- 스킬 아이콘 108개: `public/art/skills/<영웅id>_<0|1|2>.png` → 전투 HUD 스킬 버튼·영웅 정보 스킬 탭에서 지금 기호 아이콘 대신. 없으면 기호 아이콘 그대로.

## 6. 황짐승 그림 교체 (올라오면)
- 초상화·전신·컷인·코스튬에서 가슴 노출 줄인 판으로 같은 파일 이름 덮어씀 → 코드 할 일 없음(캐시만 확인).
