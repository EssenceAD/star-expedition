# 그림 규칙 (10/18 확정 · 모든 그림 작업의 기준)

## 1. 통일감이 최우선
- **기준 그림 = 지금 영웅 전신 일러스트 36장.** 레트로 2D 오락실 RPG 느낌의 잉크 외곽선, 손으로 칠한 셀 명암이에요. 새로 들어오는 그림은 전부 이것에 맞춰요. 기존 그림을 새 도구에 맞추지 않아요.
- 광택, 크롬, 3D 렌더 느낌은 금지예요.
- 같은 역할의 부품은 모든 화면에서 같은 그림을 써요.

## 2. 도구 나눔
| 도구 | 맡는 것 | 이유 |
|---|---|---|
| ChatGPT | 일러스트, 초상화, 컷인, 전투 도트, 몹, 보스 | 기존 그림을 참고로 넣어 같은 캐릭터를 유지하는 데 강해요 |
| Midjourney | HUD·UI 키트, 마을·지역 배경, 스킬 아이콘, 그림 글씨 | 질감과 장식에 강해요. 기존 일러스트를 `--sref`로 넣고 `--no glossy, chrome, 3d`로 광택을 빼요 |

- Midjourney로 캐릭터나 동작을 만들지 않아요. 10/18에 시험했는데 칸마다 생김새가 달라졌어요.

## 3. 잘림 금지
- **여백:** 모든 캐릭터·몹·보스 그림은 칸 안에서 사방 여백을 **30% 이상** 두고 요청해요. 무기, 망토 끝, 이펙트까지 다 포함이에요.
- **윤곽 있는 이펙트는 다시 그려요.** 불꽃이 퍼지는 모양, 둥근 끝, 광선 끝, 베기 궤적처럼 윤곽이 분명한 이펙트가 칸 경계에서 잘렸으면 흐리게 덮지 않아요. 전체 윤곽이 칸 안에 들어오게 다시 그려요.
- **광선:** 칸 밖으로 뻗는 광선은 그림에서 빼요. 게임이 따로 그리는 이펙트(`fx/`)로 처리해요.
- **검사 도구:** 새 그림을 넣을 때마다 `python3 tools/art_audit.py`를 돌려요. 잘린 그림이 1장이라도 있으면 넣지 않아요. Code도 배포 전에 이걸 돌리고, 결과가 0장이 아니면 배포하지 않아요.
- **이펙트 JPG:** 가장자리까지 완전한 검정(0)이어야 해요. 아니면 빛을 더하는 방식으로 그릴 때 네모가 비쳐요.

## 4. 스킬 아이콘 (Midjourney)
- 와우 스킬 아이콘처럼 **무엇을 하는 기술인지 한눈에 보이는 물건·동작**으로 그려요. 예: 대검이 땅을 가르는 모습, 방패, 화살 세 대, 회복하는 손.
- 마법진이나 빛 덩어리만 있는 아이콘은 금지예요.
- 정사각 꽉 찬 그림에 속성 색을 쓰고, 화풍은 일러스트와 같은 잉크 외곽선과 셀 명암이에요.
