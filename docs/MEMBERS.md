# 멤버 영웅 기준표 (형철 확정 2026-10-17 · 이 표가 최우선)

멤버 영웅 = 17명. 분류는 아래 셋뿐이다.

| 분류 | 영웅 |
|---|---|
| 개척자 (「체크인」 다섯 별 · 체크인 초상화 기반) | 웅스 · 고느끼 · 이카몰리 · 왈왈콩선생 · 따뜻한밤 |
| 기존 추가 멤버 (11) | 세르미뉴 · 클레이네 · 팬더 · 부브 · 하응 · 이치애 · 재희아빠 · 유월 · 깡토끼 · 딸기망고모찌 · 신야군 |
| 나 (형철 본인) | 황짐승 |

- 세르미뉴·이치애·재희아빠·딸기망고모찌는 「나중에 추가된 4명」으로 따로 취급하지 않는다. 다른 추가 멤버와 완전히 같은 급(데이터 origin·가격·길드 명단·타이틀 아트·외전 등).
- 그 외 영웅 19명(전설 14 · 스토리 5)은 오리지널 영웅.
- 실멤버 길드 「별의 원정대」 명단 = 위 17명.

## 인물 관계 (형철 제공)
- 고느끼·왈왈콩선생 현실 친구, 웅스도 친함(셋 다 부산, 웅스가 동생)
- 부브·팬더 조금 친함 / 하응·유월 친함 / 신야군 독자노선 / 깡토끼·이카몰리 현실 친구 / 따뜻한밤은 기존 성격 그대로
- 클레이네 ↔ 황짐승: 아는 사람만 아는 옛 원정 동료
- 재희아빠 ↔ 따뜻한밤 현실 친구 / 이치애 = 게임에서 만난 길드원 / 딸기망고모찌 ↔ 깡토끼 친함
- 세르미뉴: 모두의 리스펙(「세르님」), 신야군과는 스승·제자

## 이번에 고친 것
- `data/heroes.ts`: 4명의 origin 'member' → 'founder' (다른 추가 멤버와 같게)
- `config.ts`: 영웅 값 member 4,000 → 3,000 (멤버 영웅 값 통일)
- **남은 것 (Code)**: 화면·문서에서 「창립 13명」「멤버 4명 추가」 같은 표현이 있으면 이 표 기준으로 고치기. 타이틀 키 아트는 13명만 그려져 있음 → 17명 버전 다시 뽑을 예정(기획 쪽 Claude).
