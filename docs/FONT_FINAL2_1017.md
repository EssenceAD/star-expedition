# 글씨·테두리 마무리 2차 (10/17 17:14 형철 피드백)

캡처: `docs/captures/feedback_1714_1~6.png` (로비 · 영웅 정보 성장/스킬 · 상점 · 가방 · 승리)
형철: 「빨간 부분은 아직 테두리랑 글씨체. 아래 텍스트가 길어서 캐릭터 얼굴을 가림 — 글자수가 길면 글씨 크기를 낮춰서라도 영웅 표시 줄은 통일, 얼굴 가리지 않게」「첫 화면(로비) 도트 캐릭터가 너무 작음, 조금 더 키우기」

## 1. 로비 걷는 도트 영웅 크게
- 로비 광장 걷는 영웅 표시 크기 **1.4배**. 발 위치는 광장 바닥 그대로, 서로 너무 겹치지 않게 걷는 간격도 넓히기.

## 2. 영웅 카드 정보 띠 — 높이 고정 (가장 중요)
- 상점·영웅 목록·편성 등 **모든 영웅 카드**: 아래 정보 띠 = 칩 줄 / 이름 / 설명 / 가격 **각 1줄, 높이 고정**. 띠 위쪽 경계가 모든 카드에서 같은 높이.
- 글자가 길면 줄을 늘리지 말고 **글씨를 줄여서 1줄**: 이름 17→최소 13px, 설명 12→최소 10px (그래도 넘치면 말줄임 …). `scrollWidth > clientWidth`면 0.5px씩 줄이는 fit 함수 하나 만들어 공통 사용.
- 예: 세레스 「왕실 기사 — 땋은 왕관 머리의 수줍은 모범생」 2줄 → 1줄, 이름·칩이 얼굴 위로 안 올라감.
- 영웅 정보 이름 판 설명: 같은 fit, 2줄 고정. 단어 중간 갈라짐(「온/천」) 없게 `word-break: keep-all`.
- 스킬 설명(「적 모두에게 공격력 140% × 2번」 잘림): 같은 fit, 2줄까지.

## 3. 남은 테두리 — 밝은 선 상자 전부 없애기
자리: 영웅 정보 탭 6개, 상점 위치 탭(전체·전방·중앙·후방), 가방 탭(장비·성장·소모품·룬·기타)·정렬 탭(등급·전투력·강화·부위), 가방 「일반 이하」 선택 상자, 영웅 목록 이름 칸.
- **테두리 없음 + 남색 반투명 알약**, 선택된 것만 금 그라데이션 + 금 밑줄 2px.
- 「일반 이하」 select: appearance:none, 같은 알약 + 금 ▾.
- 영웅 목록 이름: 따로 테두리 상자 없애고 초상화 아래 남색 그라데이션 띠 위 글씨.
- 상점 세로 탭 「영웅」 아이콘·글씨 겹침 → 아이콘 고정폭 28px, 글씨 그 오른쪽.

## 4. 각성·초월 보석 점
- 지금 ◇ 글자처럼 보임 → CSS 보석: 12px 정사각 rotate(45deg), 찬 칸 `radial-gradient(#ffe9a6,#c99a3b)` + 금빛 그림자, 빈 칸 `#1d2a4c` + 금테 1px. 글자 ◇/○ 쓰지 말 것.
