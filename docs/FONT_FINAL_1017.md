# 글씨·테두리 마무리 (10/17 16:45 형철 피드백) — 비주얼 마지막 단계

형철: 「원하는 퀄의 나머지는 거의 다 구현됨. 빨간 표시는 거의 다 폰트 쪽 + 남아 있는 테두리만 보완하면 비주얼은 끝」
캡처: `docs/captures/feedback_1645_1~6.png` (로비 · 영웅 정보 성장/스킬 · 상점 · 가방 · 승리)

## 1. 글씨 체계 — 3종으로 통일 (지금은 본문 IBM Plex Sans가 그림 UI와 따로 놂)
| 쓰임 | 서체 | 모양 |
|---|---|---|
| 제목·영웅 이름·화면 이름·메달 이름 | **Hahmlet 700** | 크림 `#f6ecd6` + 진갈색 외곽선 1.5px + 아래 그림자 |
| 그 밖의 모든 글씨(목록·설명·버튼·탭·칩·토스트) | **Noto Serif KR 600** (Google Fonts) | 크림/흰색 + 남색 그림자 `0 1px 2px rgba(10,16,32,.8)` — 남색 판 위 그림자 글씨 |
| 숫자 | Cinzel 600 (유지) | 금/크림 |
- IBM Plex Sans KR는 **빼기**(폴백만). 회색 `#9aa` 류 보조 글씨는 크림 70% 투명으로.
- 글씨 크기 3단계만: 12 / 14 / 17px(제목 20). 지금 섞여 있는 10~11px 글씨는 12로.

## 2. 자리별 (빨간 표시)
**로비 (1)**
- 「원정대장 Lv.1」: Hahmlet, Lv는 금 숫자 작게.
- 진행 중·이벤트 목록: Noto Serif, 아이콘과 글씨 세로 가운데 맞춤, 줄 높이 같게.
- 오른쪽 큰 메달 이름(월드 보스·레이드·모험): 작은 금 리본이 메달에 비해 너무 작음 → 리본 폭 = 메달 폭 90%, 글씨 13px Hahmlet.
- **아래 메뉴: 「영웅」「편성」 두 개 이름이 빠져 있음** → 넣기. 모든 이름 같은 높이·같은 크기.

**영웅 정보 (2·3)**
- 왼쪽 목록 초상화 아래 이름: 너무 작고 칸에 끼임 → 12px, 초상화 아래 남색 띠 안 가운데.
- 이름 판(웅스 ★ / 첫 번째 칼날·전사·전방·전투력 / 설명): 이름 Hahmlet 20, 둘째 줄 Noto 12 크림 80%, 설명 Noto 12 두 줄.
- 「각성 ○○○○○ 초월 ○○○○○」: 글자 동그라미(○) 대신 **그림 점**(빈 칸=어두운 보석, 찬 칸=금 보석) — `ui/icons/star.png` 축소나 CSS 보석 점.
- 성장 줄(경험치 물약·각성·별): 아이콘·글씨·버튼 세로 가운데 정렬, 글씨 Noto 13.
- 스킬 탭: 「스킬북 3권…」 머리줄, 스킬 이름(Hahmlet 14)·마나/쿨(금 숫자 12)·설명(Noto 12) 세 단계로.
- 능력치 표 왼쪽 이름(체력·공격력…): Noto 13, 아이콘과 같은 줄 높이.
- 토스트(「4칸 바뀌었어요」): 위 이름 판을 가림 → **재화 바 바로 아래 오른쪽**(채팅 줄 자리 위)이나 화면 가운데 아래쪽으로, 남색 유리+금테, 1.5초.

**상점 (4)**
- 토스트 같은 규칙.
- 카드의 「전방·전사」 칩: 흰 네모 칩이 그림 위에서 튐 → 작은 남색 반투명 알약 + 아이콘 + 크림 글씨.

**가방 (5)**
- 탭 「장비」: 아이콘이 글씨 위에 겹침 → 아이콘 왼쪽·글씨 오른쪽 간격 4px(모든 탭 같은 규칙).
- 「정렬」 글씨가 칸 밖으로 잘림 → 정렬 줄 앞 라벨 지우고 정렬 아이콘으로.
- 「칸 +10 / 100」 버튼: 아이콘·글씨 겹침 → 같은 규칙.

**승리 (6)**
- 결과 띠 오른쪽 끝 테두리가 빈 채로 튀어나옴(금테 끝 처리 깨짐) → 띠 border-image 오른쪽 조각 확인.
- 결과 글씨 Noto 13, 「최고 기록!」은 금, MVP 이름 Hahmlet.

## 3. 남은 테두리
- 크림/흰색 1px 테두리 남은 곳 전부 찾아서 UI 키트 금테 또는 없음으로(검색: `border: .*solid var(--c-line)` 등).
- 버튼·칩·토스트 모서리 반경 한 값으로.
