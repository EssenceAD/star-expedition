# 전투 도트 전원 교체 (10/17)

형철 요청: 「전투 도트 크기 맞추기 + 패배·피격·승리 자세까지 디테일 맞추기」, 「머리 크기는 다 비슷해야 함」.

## 무엇이 있나
- `public/art/px/<영웅id>/` — **36명 전원**, 칸 8장 + `_parts.json` (지금 시트 형식 그대로: x,y,w,h,cw,ch,ax)
- 비율: 4.5~5등신 (예전 2.5등신 짜리몽땅 → 형철 확정 「그렇지 이거야」)
- **머리(정수리~턱)는 모두 약 48px(±12%)로 저장** → 화면에서 **모든 영웅에 같은 배율**을 쓰면 얼굴 크기가 거의 같다.
- **키는 체급별 (형철 15:02 지시)**: 근육·덩치 남캐(그롬·팬더·웅스·부브·레온·재희아빠) 264 > 일반 남캐 = 생머리·글래머 여캐(클레이네·스칼렛·비비안·베로니카·노엘·엘리시아·이치애·아리아) 240 > 작게 설계된 여캐(고느끼·깡토끼·왈왈·이카몰리·세레스·류카·루나·에일라·연화·닉스) 218 > 미미·모스 할머니 187 (저장 px). 체급은 `_heads.json`의 tier.
- 비교표: `docs/sprites_all36.png` · 원본 시트: `art_raw/px/sheet_<id>.jpg`

## Code가 할 것
1. `heroes.ts` SHEETS: 36명 모두 `px/<id>` 시트로 (임시 색바꾸기 tint · 직업 기본 시트 대신). 예전 w1·w2·gonu 등 파일럿 시트는 안 씀.
2. HEIGHT(영웅마다 다른 화면 키) 대신 **배율 하나**: 화면 머리 높이 = (예) 26 논리px → 배율 = 26/48. 모든 영웅 같은 값. 그래야 얼굴 크기가 같다.
3. 발 기준선: 지금 sheet.ts 방식(줄마다 아래 끝) 유지 — r1c1(누운 자세)도 바닥에 붙게.
4. 승리 화면에서 살아남은 영웅 전원 `win` 자세, 패배 시 `down` 유지, 맞을 때 `hurt`.
5. 844×390에서 전투 캡처: 4명 파티(웅스·고느끼·클레이네·그롬처럼 체격 다른 조합)로 대기·공격·피격·승리·패배 한 장씩.
