## ① 영웅 36명 — `public/art/px2/<id>/` (기존 8칸은 그대로 둠)
새 칸 16장이 같은 폴더에 들어 있다. 크기는 기존 r0c0 키에 맞춰 놨으므로 `PX_H`는 그대로 쓰면 된다.

| 동작 | 칸 | 권장 타이밍 |
|---|---|---|
| 대기(숨쉬기) | `m1r1c0~c3` 반복 | 칸마다 170ms |
| 걷기 | `m1r0c0~c3` 반복 | 칸마다 110ms (이동 속도에 맞춰) |
| 평타 | `m2r0c0`(준비) → `c1`(휘두름) → **`c2`(타격, hit)** → `c3`(회수) | 200 / 60 / 160 / 150ms |
| 스킬 1·2·3 | `m2r1c0`(기 모으기) → `c1`(큰 준비) → **`c2`(발동, hit)** → `c3`(마무리) | 300 / 120 / 380 / 300ms (스킬3은 컷인 뒤 같은 칸) |
| 피격 | 기존 `r1c0` | — |
| 쓰러짐 | 기존 `r1c1` | — |
| 승리 | 기존 `r1c2` | — |

- 스킬 1·2·3은 그림이 같다. 셋은 **이펙트(②)·내딛기 거리·속도**로 구분한다. 스킬1은 0.8배 속도, 스킬3은 컷인 뒤 0.7배 슬로우.
- **타격감**:
  - hit 칸에서 히트스톱 60ms를 준다(양쪽 다 멈춤).
  - 치명타와 스킬3은 화면 흔들림 4px / 120ms.
- **잘림 해결**:
  - 스킬 칸은 이펙트 때문에 칸이 넓다(`cw`·`ch`).
  - `render.ts`의 `off` 캔버스(지금 360)를 **프레임 칸 크기 × 배율에 맞춰 키운다**(최소 520×520 논리 px). 그래야 스킬 쓸 때 잘리지 않는다.
- 로비 걷기도 `m1r0`을 쓴다. 지금은 대기 2칸을 번갈아 보여 주고 있어서 걷는 것처럼 안 보인다.
- 용량: px2 전체 58MB. 영웅 1명이 약 1.6MB라서 **필요한 영웅만 불러오기(⓪에서 만든 것)를 유지**한다. 여유가 되면 빌드할 때 WebP로 바꿔도 된다(sharp, 품질 90).

## ② 스킬 이펙트 14종 — `public/art/fx/<name>/0~3.jpg` + `_fx.json`
- **검은 배경, 흰색 그림**이다.
  - 그릴 때 `globalCompositeOperation = 'lighter'`를 쓰면 검정이 사라진다.
  - **속성 색 입히기**: 보조 캔버스에 그린 뒤 `'multiply'`로 속성색 `fillRect`를 하고, 그 결과를 본 캔버스에 `'lighter'`로 그린다.
- 앵커: `_fx.json`의 `anchor`를 따른다.
  - `center`: 대상 중심(몸통 높이)
  - `bottom`: 대상 발밑
- 4칸은 칸마다 70~90ms씩 재생한다.
- `Vfx` 이름과 1:1로 맞춘다: `slash smash pierce bolt burst meteor ring heal shield pillar`.
- 추가 이펙트:

| 이펙트 | 언제 |
|---|---|
| `hit` | 평타 맞을 때 |
| `crit` | 치명타 |
| `buff` | 버프 걸릴 때 |
| `stun` | 기절 머리 위 반복 |

- **보호막(콩선생 등)**:
  - 걸릴 때 `shield` 0→1을 재생한다.
  - 보호막이 남아 있는 동안 1↔2를 600ms마다 반복하고, 알파 0.7로 대상 몸에 겹친다.
  - 깨질 때 3을 재생한다.
  - 지금 그리고 있는 타원은 지운다.
- `bolt`(투사체)는 시전자에서 대상까지 날아간다. 0~2를 반복하며 이동하고, 도착하면 3을 재생한다.
- `meteor`는 대상 위 오른쪽에서 떨어진다. 0~1은 낙하, 2~3은 착지다.

## ③ 지역 배경 · 지역 몹 · 장 보스
### 배경 — `public/art/bgs/region_<key>.jpg` (2048×768)
- key: `forest swamp mine ice abyss coast dune ember sky deep` (= `CHAPTERS[].region`)
- 스토리 전투는 장의 region 배경을 쓰고, **지역 색 입히기(region tint)는 끈다**. 지금처럼 같은 그림에 색만 바꾸는 방식은 쓰지 않는다.
- 땅 높이는 기존 bg.jpg와 비슷하게 맞춰 그렸다(아래 35%가 길). 발 위치가 어색하면 지역별 `groundY` 보정값을 한 줄 두고 조정한다.

### 몹 — `public/art/mobs2/<key>/` (5열×3행)
- 행: `r0` 슬라임, `r1` 고블린, `r2` 늑대 (`MOB_KINDS` 그대로)
- 열: `c0` 대기, `c1` 대기2, `c2` 공격 준비, **`c3` 공격(hit)**, `c4` 피격
- 모두 **왼쪽을 본다**(적 진영).
- 죽을 때는 `c4`를 보여 준 뒤 0.4초 동안 아래로 가라앉으며 사라진다.
- `mobTint`는 이 그림에 적용하지 않는다(그림 자체가 지역 색이다).
- 이름은 `CHAPTER_MOBS` 그대로 맞춘다. 예: 1장 민트 슬라임 / 두건 고블린 / 수정 늑대 = forest.

### 장 보스 — `public/art/bosses2/<key>/` (4×2)
| 칸 | 동작 | 쓰는 패턴 |
|---|---|---|
| r0c0, r0c1 | 대기 반복 | — |
| r0c2 → **r0c3** | 내려찍기 준비 → 타격 | `slam`, `quake` (경고 시간 내내 r0c2를 유지하고 살짝 떨림) |
| r1c0 → **r1c1** | 기 모으기 → 광선 | `beam`, `focus` |
| r1c2 | 포효 | `roar` |
| r1c3 | 비틀거림 | 쓰러질 때(이 칸 뒤에 흔들리며 사라짐) |

- 경고(`warn`) 동안 준비 칸을 보여 준다. 그래야 **언제 공격하는지 보인다**. 지금은 이게 안 보여서 "나무판떼기"처럼 느껴진다.
- 1장 「호박눈」 = forest, 2장 「곰팡이왕」 = swamp … 10장 「별을 삼킨 것의 그림자」 = deep.
