# v0.12.0 되돌리기 + 어제 피드백 다시 (10/18 아침 · Code용)

## 왜 되돌리나
- v0.12.0(UI_KIT_1018)은 형철이 불합격 판정했다. 캡처: `docs/captures/feedback_1018/v0120_1~6.jpg`(불합격), `v0120_7.jpg`(**이전 v0.11.5 — 형철이 이쪽이 낫다고 함**).
- 불합격 이유(형철):
  - 플래시 게임처럼 보인다. 오락실 감성이 없다.
  - 화면끼리 싱크가 안 맞는다. 새 틀 화면과 옛 화면(모험 지도 등)이 섞여 있다.
  - 폰트가 안 맞는다. 틀 그림을 크게 늘려서 흐리고 뭉툭하다.
  - 팝업 안 글씨가 틀에 걸린다(`v0120_1` 「7시간 20분…」·「금화」, `v0120_3` 「랭킹·우편·채팅…」).
  - 팝업 아래가 텅 비었다.
  - **두 번째 웨이브부터 영웅이 걷지 않고 멈춘 채 미끄러진다.**
- 실패 원인(기록용): 정답 화면을 형철 승인 없이 구현했다. 844×390 기준을 PC에서 통째로 키웠다. 키트로 화면을 한꺼번에 갈아엎었다. 이번엔 **옛 화면(v0.11.5)을 바탕으로 하나씩만 고친다.**

## 1단계부터: 어제 형철 피드백을 옛 화면 위에서 하나씩
**규칙**
- **한 번에 한 묶음(아래 A·B·C…)만.** 묶음이 끝날 때마다 고치기 전과 후를 나란히 붙인 캡처를 두 크기로 보고하고 멈춘다.
  - **PC:** 1920×1040 창, 형철 화면과 같게.
  - **폰:** 844×390 @2.
- UI를 통째로 확대하지 않는다. 지금 v0.11.5의 크기·밀도를 유지한다.
- 새 틀 그림(kit2)은 형철이 그 부품을 보고 OK한 것만 쓴다. 옛 틀을 새 틀로 바꾸자는 판단은 Code가 하지 않는다.
- 글씨체는 이번에 바꾸지 않는다(G 묶음에서 형철이 견본을 보고 정한다).
- 형철이 빨간 표시한 원본 캡처 `docs/captures/feedback_*.png`(1612·1645·1714 각 6장, battle_1017)를 **한 장씩 열어 표시된 곳마다 목록**을 만들고(`docs/RECOVER_1018_list.md`), 그 목록 순서로 고친다. 아래 항목은 그 중 핵심이다.

### A. 전투 아래 영웅 카드 (지금 카드 모양 유지)
1. **초상화 얼굴이 잘림**(웅스 머리 반이 카드 밖).
   - 영웅마다 얼굴 중심 `faceX, faceY`(0~1)를 두고, 그 점이 초상 칸의 가로 50%·세로 42%에 오게 자른다.
   - 36명 확인 시트를 한 장으로 만든다. 눈 두 개가 다 보이고 정수리가 잘리지 않아야 한다.
2. 초상화가 위 금테 밖으로 삐져나옴 → 카드 안쪽으로 clip.
3. 이름·직업·Lv 글씨가 금테 선에 걸침 → 안쪽 선보다 6px 아래, 이름 뒤에 남색 반투명 띠.
4. 스킬 아이콘 오른쪽 아래 작은 숫자가 테두리와 겹침 → 빼거나 아이콘 밖 아래로.
5. **스킬 아이콘이 받침 배경을 덮어 버림.** 새 아이콘(정사각 192px)을 둥근 받침 안쪽 원에 맞춰 원형으로 잘라 넣는 안과, 받침을 정사각으로 바꾸는 안을 **두 가지 다 캡처해서 형철에게 고르게 한다.**
6. 버프·디버프 네모의 CSS 테두리 제거(아이콘만). 버프 아이콘 그림은 따로 준비된다.

### B. 전투 흐름
1. **버그: 두 번째 웨이브부터 영웅이 멈춘 채 미끄러짐.** 웨이브 사이 이동 때는 늘 걷기 동작이어야 한다. v0.11.5에서도 그런지 먼저 확인하고 고친다. 1·2·3웨이브 이동을 각각 GIF로 찍어 보고한다.
2. 걷기가 통통 튀지 않게: 위아래 흔들림 0~1px, 도트 프레임만 넘긴다.
3. 영웅·몹 발밑 그림자(미리 그린 흐린 타원). 발이 그림자에 닿게 해서 공중에 뜬 느낌을 없앤다.
4. 궁극기: 컷인 → 0.2초 히트스톱 → 발동. 일반 스킬은 컷인 없음.

### C. 피해량 미터·위 버튼 (HUD_FIX_1017 B·C 그대로)
- 미터 안 글씨는 한 가지 본문체. 숫자는 tabular.
- 「1,295/초」는 막대 밖으로. 글씨와 막대가 1px도 겹치지 않게.
- 빈 이름판에 「피해량」 제목.
- 마지막 줄이 아래 장식에 걸리지 않게.
- 접기 손잡이를 판에 붙인다.
- 「자동」「×1」은 알약 안에.

### D. 보상·결과
1. **방치 보상 팝업 깨짐 버그**(글씨 거대, 카드 잘림, 가로 스크롤). 원인은 이미 찾았다: 결과 화면용 CSS `.rw div span { font-size: 40px }`이 로비 「그동안 원정대는…」 팝업에도 먹는다. 선택자 범위를 결과 화면으로 좁힌다.
2. 결과 화면 자체는 옛 모습 유지. 형철 캡처의 지적만 고친다.

### E. 대화
- 말풍선 테두리와 스킵 버튼을 형철 캡처 지적대로 고친다(feedback 캡처 목록 참조).

### F. 안전 여백·기기 대응
- 바깥 요소는 `max(지금 여백, env(safe-area-inset-*))`. `viewport-fit=cover`.
- 아이폰 노치·아이패드에서 가려지지 않게. **UI를 확대하지 않는다.**

### G. 형철이 고를 것 (견본만 만들고 적용은 OK 후)
1. 이름 W.I.N.D: 글자 바꾸기(title, manifest, 화면 글자)만 할지, 새 타이틀 화면(`ui/title/` 키아트·로고)까지 할지. 새 타이틀 견본 1장을 캡처해서 보여 준다.
2. 글씨체: 지금 것 유지 vs Gothic A1. 전투·로비 각 1장으로 비교 견본.
3. 스토리 대사 264줄(`docs/STORY_DRAFT_1018.md`)은 형철 검수 후 연결. 3·6스테이지 전 대사 칸(`mid3`·`mid6`) 추가는 그때.
